### ISSUE-1301: ボスラッシュのタイブレーク指標が DB 定義と食い違い、かつ「全滅時」では常に 0 になる

| 項目 | 値 |
|------|-----|
| カテゴリ | 整合性 |
| 重要度 | 高 |
| 関連ファイル | docs/design/systems/endgame.md, docs/tech/basic/tech_db/battle.md |
| 該当箇所 | endgame.md §2.11「ランキング」表（41行目）, tech_db/battle.md §2（38行目） |
| 検出可能工程 | 基本設計（DB設計とゲーム仕様の突合） |

**問題の説明:**

`endgame.md` §2.11 は
> `| タイブレーク | 同ウェーブの場合、全滅時の残HP合計が高いほど上位 |`

としているが、同§の概要は「**全滅するまで戦い続け**」（9行目）であり、全滅＝パーティ全員 HP 0 のため **残HP合計は常に 0 になり、タイブレーク指標として機能しない**。

一方 `tech_db/battle.md` §2 の列定義は
> `| best_wave_hp | INTEGER | 不可 | 0 | ベスト到達時の残HP合計。同ウェーブのタイブレーク |`

で、**「全滅時」ではなく「ベスト到達時」**の残HPを持つとしている。どちらの時点で記録するかで値が変わるため、実装が分岐する。

**修正案:**

- `docs/design/systems/endgame.md` §2.11「ランキング」表のタイブレーク行を、DB 定義に合わせて次へ差し替える:
  `| タイブレーク | 同ウェーブの場合、**そのウェーブを突破した時点**のパーティ残HP合計が高いほど上位（記録は `boss_rush_states.best_wave_hp`） |`
- 併せて「全滅するまで戦い続け」（9行目）の直後に、記録時点が**ウェーブ突破時**であることを1文で明記する（全滅したウェーブは突破していないため記録対象外）。
- `docs/tech/basic/tech_db/battle.md` §2 の `best_wave_hp` 備考へ「`best_wave` を更新したウェーブの突破直後に同時更新する」を追記し、更新タイミングを一意にする。
