### ISSUE-003: 限界突破の効果説明が「固定ボーナス加算」と記載されているが、実際は割合ボーナス

**問題の説明:**

### ISSUE-004: レジェンダリー装備の付与ステータス数が5だが、ステータス種は4種のみ

| 項目 | 値 |
|------|-----|
| カテゴリ | 整合性 |
| 重要度 | 中 |
| 関連ファイル | docs/game_spec.md |
| 該当箇所 | game_spec.md §2.4 レアリティテーブル |

**問題の説明:**
game_spec.md §2.4 のレアリティテーブルで、レジェンダリー装備の「付与ステータス数」が5と定義されている。しかし装備に付与可能なステータス種は ATK / DEF / HP / SPD の4種のみ。5つのステータスを付与するには、同一ステータスの重複付与が必要になるが、その仕様が明記されていない。

| レアリティ | 付与ステータス数 |
|-----------|----------------|
| レジェンダリー | 5 |

**修正案:**
以下のいずれかを選択:
1. レジェンダリーの付与ステータス数を **4** に変更（全ステータスが付く特別感を維持）
2. 同一ステータスの重複付与を許可する仕様を明記（例: ATKが2回付与された場合は加算）
3. 5つ目のステータスとして新しい効果（クリティカル率、HP吸収率など）を追加

### ISSUE-009: 装備売却・換金アイテム売却の API が tech_spec.md に未定義
