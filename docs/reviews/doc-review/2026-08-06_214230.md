### ISSUE-1101: 回復の心得（heal_p1）の適用範囲が 003_回復系統.md（蘇生に適用）と tech_skill.md（蘇生に適用しない）で矛盾

| 項目 | 値 |
|------|-----|
| カテゴリ | 整合性 |
| 重要度 | 高 |
| 関連ファイル | docs/data/skills/003_回復系統.md, docs/tech/detail/tech_skill.md |

| 検出可能工程 | 本レビュー |

**問題の説明:**
003_回復系統.md の `heal_p1` 回復の心得は「追加効果 | ヒール・全体回復・**蘇生の回復量**に適用。リジェネには適用されない」。一方 tech_skill.md §1 #5（適用の一意化）は「回復量+%（回復の心得）| ATK係数の回復スキル（`heal_1`・`heal_2`）にのみ乗算。**蘇生の復活HP30%**・リジェネ・ポーションには**適用しない**」としており、蘇生への適用有無が正反対。003_回復系統.md 自身の設計メモ「リジェネはmaxHP基準のため対象外」の論理では、蘇生（復活HP = maxHP×30%）も maxHP 基準のため対象外とするのが一貫する。

**修正案:**
- docs/data/skills/003_回復系統.md §4 `heal_p1` の「追加効果」を「ヒール・全体回復の回復量に適用。蘇生（復活HPはmaxHP基準）・リジェネには適用されない」へ修正する（tech_skill.md §1 #5 に合わせる）
- 「回復量+%の適用範囲」のトピックの正（tech_skill.md §1）を docs/spec_ownership.md へ登録する
