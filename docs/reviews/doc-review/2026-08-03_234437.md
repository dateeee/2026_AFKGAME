### ISSUE-1003: 装備レアリティの階層補正式に100%キャップがなく天空の塔60Fで確率が破綻する

| 項目 | 値 |
|------|-----|
| カテゴリ | 整合性 |
| 重要度 | 高 |
| 関連ファイル | docs/design/systems/equipment.md, docs/design/systems/dungeon.md, docs/data/master/base.md |
| 該当箇所 | equipment.md「レアリティ出現率(階層依存)」 / base.md §10.2 |
| 検出可能工程 | 本レビュー |

**問題の説明:**
base.md §10.2 は素材ドロップ率について「実効ドロップ率は…`基準率 × (1 + 0.05 × 階層)` で算出し、100% を上限とする」と上限を明記。同型の式を使う装備レアリティ出現率は equipment.md「階層補正: 補正後確率 = 基本確率 × (1 + 0.05 × 階層)」「コモン確率は残余（100% − 他の合計）で自動調整」のみで上限指定がない。天空の塔60F（倍率4.0）ではアンコモン25%×4=100%、レア10%×4=40%、エピック4%×4=16%、レジェンダリー0.5%×4=2%で合計158%となり、コモンの残余が負値になる実装不能な状態が通常到達可能な塔で発生する。

**修正案:**
- docs/design/systems/equipment.md「レアリティ出現率（階層依存）」に、合計100%上限と超過時の正規化ルール（例: コモン以外の合計が100%超なら、コモンを0%とし他レアリティを比率按分で合計100%に正規化）を追記する
