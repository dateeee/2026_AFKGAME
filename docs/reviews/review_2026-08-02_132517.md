**問題の説明:**

**修正案:**

### ISSUE-003: 基礎値計算式の変数名が「敵LV」のままでショップ・製作に適用できない

| 項目 | 値 |
|------|-----|
| カテゴリ | 整合性 |
| 重要度 | 中 |
| 関連ファイル | docs/data/master/equipment.md, docs/design/systems/equipment.md |
| 該当箇所 | master/equipment.md §6.1（行70）/ systems/equipment.md「装備の基礎ステータス値」（行74） |

**問題の説明:**

master/equipment.md §6.1 は「装備レベルの決定ルール」として3種を定義している。

```
- **ドロップ**: 倒した敵のLVと同じ
- **ショップ購入**: プレイヤーの最高到達階層と同じ（下限1）
- **製作**: プレイヤーの最高到達階層の敵LVと同じ
```

その直後の計算式は `基礎値 = floor(敵LV × 1.5 + 2)` と、変数名が「敵LV」に固定されている。ショップ購入の装備レベルは階層由来であって敵LVではないため、式をそのまま読むと適用先が不明になる。tech_shop.md §2.5 は正しく `基礎値 B = floor(L × 1.5 + 2)`（`L` = 装備レベル）と書いており、表記が食い違っている。同じ問題が systems/equipment.md「装備の基礎ステータス値」にもある。

**修正案:**

- `docs/data/master/equipment.md` §6.1: `基礎値 = floor(敵LV × 1.5 + 2)` を `基礎値 = floor(装備レベル × 1.5 + 2)` に修正する。§6.2 の参考値表の見出し「敵LV」も「装備レベル」に統一する
- `docs/design/systems/equipment.md`「装備の基礎ステータス値」: 同様に「敵LV」を「装備レベル」に修正する（ISSUE-004 の対応で当該節をリンクへ置き換える場合は不要）
