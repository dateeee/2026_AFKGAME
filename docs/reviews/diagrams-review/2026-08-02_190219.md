### ISSUE-401: システム構成図の Components 層が実装と完全に食い違っている

| 項目 | 値 |
|------|-----|
| カテゴリ | コードとの整合性 |
| 重要度 | 高 |
| 関連ファイル | diagrams/system_architecture/application.md, docs/tech/tech_structure.md, docs/tech/tech_design_system.md |
| 該当箇所 | application.md 行25〜32（`Components` サブグラフ）、行61〜65（`GameView --> ...` の依存辺） |

**問題の説明:**

`application.md` の `Components` サブグラフは6ノードを描いている。

```
BattleLog["BattleLog.vue\n戦闘ログ表示\n自動スクロール"]
CharStatus["CharacterStatus.vue\nLV/HP/ATK/DEF/SPD\nEXPバー"]
TowerInfo["TowerInfo.vue\n塔名・階層・モード\n環境効果表示"]
HpBar["HpBar.vue\nHP/maxHP ゲージ\nCSS width%"]
OfflineModal["OfflineRewardModal.vue\nオフライン報酬サマリー"]
Toast["ToastNotification.vue\n最大3件・3秒消去"]
```

この6ファイルは `frontend/src/components/` に**1つも存在しない**（`git log --diff-filter=A` でも作成履歴なし）。実在するのは以下の3層20ファイルで、`tech_structure.md` §2 も `4eeebf0` で同じ3層に更新済み。

- `components/ui/` 11点（`BaseButton` `BaseCard` `BaseModal` `BaseBadge` `BaseField` `BaseSelect` `BaseTextInput` `NumberStepper` `StatBar` `AppIcon` `icons.ts`）
- `components/layout/` 5点（`AppShell` `AppHeader` `AppNav` `navItems.ts` `ConnectionBanner`）
- `components/equipment/` 4点（既存）

`tech_design_system.md`「設計方針」は3層構造（トークン → UIプリミティブ → アプリシェル）を**実装の不変条件**として定めており、図はこの層構造そのものを表現していない。この図を根拠に実装すると規約に反する構造を作ってしまう。

**修正案:**

- `diagrams/system_architecture/application.md` の `Components` サブグラフを、実装とドキュメントに合わせて描き替える。
  - サブグラフ名を `Components["Components (tech_design_system.md が正)"]` とし、以下の3ノード（または3サブグラフ）構成にする
    - `UiPrimitives["ui/ UIプリミティブ 11点\nBase{Button,Card,Modal,Badge,\nField,Select,TextInput}\nNumberStepper / StatBar / AppIcon"]`
    - `Layout["layout/ アプリシェル 5点\nAppShell (100dvh grid)\nAppHeader / AppNav / navItems.ts\nConnectionBanner (接続エラー)"]`
    - `EquipComp["equipment/ Phase2~\nEquipmentCard / Compare\nInventory / SlotGrid"]`
  - 行61〜65 の `GameView --> BattleLog` 等5本の辺を削除し、`Views --> UiPrimitives` と `Layout --> Views`（`App.vue` が `AppShell` で包む）に置き換える
- 末尾の注記に1行追加する: `- Components の3層構成（トークン / UIプリミティブ / アプリシェル）は [tech_design_system.md](../../docs/tech/tech_design_system.md) が正`
