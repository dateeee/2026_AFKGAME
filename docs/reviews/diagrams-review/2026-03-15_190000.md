### ISSUE-006: ER図 CharacterEquipSlot の主キーがコードと不一致

| 項目 | 値 |
|------|-----|
| カテゴリ | コードとの整合性 |
| 重要度 | 高 |
| 関連ファイル | diagrams/er_diagram.md, backend/app/models/equipment.py |
| 該当箇所 | er_diagram.md 行137〜142（CharacterEquipSlot定義）, equipment.py 行34〜46 |

**問題の説明:**
ER図では CharacterEquipSlot に `uuid id PK` が定義されている:

```
CharacterEquipSlot {
    uuid id PK
    uuid character_id FK "references Character.id"
    enum slot "weapon/shield/head/body/arms/waist/legs/ears/ring"
    uuid equipment_id FK "nullable, references Equipment.id"
}
```

しかし、コード（equipment.py）では `id` カラムが存在せず、複合主キー `(character_id, slot)` で実装されている:

```python
class CharacterEquipSlot(Base):
    __tablename__ = "character_equip_slots"
    character_id: Mapped[str] = mapped_column(
        String(36), ForeignKey("characters.id"), primary_key=True
    )
    slot: Mapped[str] = mapped_column(String(20), primary_key=True)
```

**修正案:**
ER図の CharacterEquipSlot を複合主キーに修正する:
```
CharacterEquipSlot {
    uuid character_id PK,FK "references Character.id"
    enum slot PK "weapon/shield/head/body/arms/waist/legs/ears/ring"
    uuid equipment_id FK "nullable, references Equipment.id"
}
```

### ISSUE-012: screen_transition.md でボスラッシュ画面の state 定義が `end` で閉じられている

| 項目 | 値 |
|------|-----|
| カテゴリ | Mermaid構文 |
| 重要度 | 中 |
| 関連ファイル | diagrams/screen_transition.md |
| 該当箇所 | screen_transition.md 行182 |

**問題の説明:**
ボスラッシュ画面の state 定義が `end` キーワードで閉じられている:

```mermaid
    state ボスラッシュ画面 {
        direction TB
        ...
        ボスラッシュ進行中 --> ボスラッシュ結果 : リタイア/全滅
        ...
    end       ← ここ
```

`stateDiagram-v2` では state の閉じ括弧は `}` であり、`end` は `flowchart` や `subgraph` の構文。多くの Mermaid レンダラーでは `end` でも動作する場合があるが、公式構文に準拠するなら `}` に修正すべき。

**修正案:**
screen_transition.md 行182 の `end` を `}` に修正する。
