**問題の説明:**

`ui.md`「アカウント欄（Phase 2〜）」は設定画面に4項目を置くと定めている。

| 項目 | 内容 | Phase |
|------|------|-------|
| 問い合わせ先 | メールまたはフォームへの導線 | 2 |
| 規約類 | 利用規約・プライバシーポリシーへの導線 | 2 |
| クレジット | 帰属表示が必要なアセットの出典 | 2 |

```
            direction TB

```

```
            規約類 : 利用規約 + プライバシーポリシー (Phase 2~)
            クレジット : アセット出典 (Phase 2~)
            退会 : 最下部に分離配置 (Phase 2~)
```

```
        state 退会確認 {
            direction TB
            [*] --> 再認証
            再認証 : パスワード or Google 再認証
            再認証 --> 削除確認 : 認証成功
            削除確認 : 復旧不可の明示
        }
        設定画面 --> 退会確認 : 退会 (Phase 2~)
```
