### ISSUE-001: ドロップ率階層補正の係数が game_spec.md 内で矛盾（0.03 vs 0.05）

| 項目 | 値 |
|------|-----|
| カテゴリ | 整合性 |
| 重要度 | 高 |
| 関連ファイル | docs/game_spec.md, docs/master_data.md, docs/glossary.md, docs/towers/*.md |
| 該当箇所 | game_spec.md §2.4（装備ドロップ率、L349）/ game_spec.md §2.6（塔概要、L487）/ master_data.md §6.1（L120）/ glossary.md（L59）/ 全塔ファイル §7 |

**問題の説明:**
game_spec.md §2.4 のドロップ率階層補正式が `補正後確率 = 基本確率 × (1 + 0.03 × 階層)` と記載されているが、以下のすべてのファイルでは係数 `0.05` が使われている:

- game_spec.md §2.6（同一ファイル内で矛盾）: `基準率 × (1 + 0.05 × 階層)`
- master_data.md §6.1: `基準ドロップ率 × (1 + 0.05 × 階層)`
- glossary.md: `基本率 × (1 + 0.05 × 階層)`
- 全塔ファイル（001〜010）§7: `基準ドロップ率 × (1 + 0.05 × 階層)`

game_spec.md §2.4 の `0.03` のみが孤立しており、他の全箇所（同ファイル含む）と矛盾している。

**修正案:**
- `game_spec.md` L349: `補正後確率 = 基本確率 × (1 + 0.03 × 階層)` → `補正後確率 = 基本確率 × (1 + 0.05 × 階層)` に修正する

|------|-----|
| カテゴリ | 整合性 |

| 段階 | スキル | SP |

| 3a | 全体回復 | 2 |
| 3b | リジェネ | 2 |
| 4 | 蘇生 | 3 |
| **合計** | | **9** |

他の5系統は各4スキル・7SPで統一されているが、回復系統のみ5スキル・9SPとなっている。SKILLS_OVERVIEW の「7SP」は回復系統には当てはまらない。

**修正案:**
- `SKILLS_OVERVIEW.md` L110 を以下に修正:
  > 1系統をTier4まで取得: 7SP（LV7で到達可能）※回復系統のみ全スキル取得に9SP（Tier3が2分岐のため）

| 塔ファイル | ヘッダー表記 |

| 001〜005, 007〜008 | `## 7. ドロップテーブル（Phase 2〜）` |
