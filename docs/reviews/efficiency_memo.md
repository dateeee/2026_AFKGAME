  非効率シグナル（同一Readの再読・同一コマンドの連発・エラー多発・許可拒否・

  Claude が「原因と改善案」を記入して完成させる

- **反映**: `/retro` スキルがエントリを読み、スキル・プロファイル・成果物の改善へ
  反映する。**反映済み・対応不要のエントリは削除する**（open_specs と同じ運用。履歴は Git が持つ）
