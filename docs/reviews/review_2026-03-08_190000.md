### ISSUE-001: アクセサリー装備スロットが未定義

| 項目 | 値 |
|------|-----|
| カテゴリ | 整合性 |
| 重要度 | 高 |
| 関連ファイル | docs/game_spec.md, docs/master_data.md |
| 該当箇所 | game_spec.md 2.4（装備スロット）/ game_spec.md 2.5（日替わり商品）/ master_data.md 4.2（アクセサリー） |

**問題の説明:**
game_spec.md 2.4 では装備スロットを8つ定義（weapon/shield/head/body/arms/waist/legs/ears）しているが、「アクセサリー」カテゴリのスロットが存在しない。
一方、game_spec.md 2.5 の日替わり商品枠で「アクセサリー1個」と記載があり、master_data.md 4.2 でも力の指輪・守りの指輪・速さのブーツ・命のペンダント・勇者のお守り等のアクセサリーが定義されている。
アクセサリーがどのスロットに装備されるのか、または専用スロットが不足しているのか不明。

**修正案:**
以下のいずれかを選択:
- **案A**: 既存の「耳」スロットを「アクセサリー」に改名し、指輪・ペンダント・ブーツ以外のアクセサリー全般を含める。ただし「速さのブーツ」は足スロット扱いにすべき
- **案B**: アクセサリー専用スロット（指輪/ネックレス等）を追加し、スロット数を拡張する
- **案C（推奨）**: master_data.md のアクセサリーを既存スロットに対応付ける（指輪→耳、ペンダント→耳、ブーツ→足）。日替わり商品の「アクセサリー1個」はいずれかのスロットカテゴリからランダムに出す「汎用枠」と再定義する

### ISSUE-002: 経験値計算式のbase_expが未定義

| 項目 | 値 |
|------|-----|
| カテゴリ | 整合性 |
| 重要度 | 中 |
| 関連ファイル | docs/game_spec.md, docs/master_data.md |
| 該当箇所 | game_spec.md 2.1（レベルアップ）/ master_data.md 1.4（経験値テーブル） |

**問題の説明:**
game_spec.md の経験値計算式は `base_exp * (level ^ 1.5)` と変数名で記載されているが、`base_exp` の具体値が定義されていない。
master_data.md では `100 * (level ^ 1.5)` と具体値100が使われている。
game_spec.md 側で `base_exp = 100` であることが明記されていないため、実装時に参照先が曖昧になる。

**修正案:**
- game_spec.md 2.1 の計算式を `100 * (level ^ 1.5)` に変更する。または `base_exp = 100` の注釈を追加する

### ISSUE-005: ポーションの敵ドロップがドロップテーブルに未定義

| 項目 | 値 |
|------|-----|
| カテゴリ | 整合性 |
| 重要度 | 中 |
| 関連ファイル | docs/game_spec.md, docs/towers/001_ゴブリンの塔.md, docs/towers/002_森の塔.md, docs/tech_spec.md |
| 該当箇所 | game_spec.md 2.3（ポーション入手方法）/ 各塔ファイル セクション7（ドロップテーブル）/ tech_spec.md 1.2（敵データ定義例） |

**問題の説明:**
game_spec.md 2.3 ではポーションの入手方法として「ショップで購入 / 敵からドロップ」と記載。
tech_spec.md 1.2 の敵データ定義例でも `dropTable: [{ "itemId": "potion", "rate": 0.1 }]` とポーションのドロップが記載されている。
しかし、ゴブリンの塔・森の塔のドロップテーブル（セクション7）には、製作用素材・装備・換金アイテムのドロップ率のみ定義されており、ポーションのドロップが含まれていない。
master_data.md 3.3 では「敵ドロップは Phase 2以降」と記載されているが、これが「ポーションの敵ドロップがPhase 2」なのか「敵ドロップ全般がPhase 2」なのか曖昧。

**修正案:**
- 各塔ファイルのドロップテーブルにポーションドロップを追加する（Phase 2〜のセクションに含める）
- または、ポーションの敵ドロップはPhase 2以降であることをgame_spec.md 2.3にも明記する（推奨: `入手方法: ショップで購入（Phase 1〜） / 敵からドロップ（Phase 2〜）`）
