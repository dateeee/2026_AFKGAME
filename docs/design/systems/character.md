# ゲーム仕様 — キャラクター・パーティ・スキル

> [game_spec.md](../game_spec.md) §2.1 / §2.7 / §2.8。数値定義は [master_data.md](../../data/master_data.md)、変更履歴は親に集約（[§7](../game_spec.md#7-変更履歴)）。

## 2.1 キャラクター

### ステータス
| パラメータ | 説明 |
|-----------|------|
| HP | 体力。0になると戦闘不能（一定時間で自動回復） |
| ATK | 攻撃力。与ダメージに影響 |
| DEF | 防御力。被ダメージ軽減 |
| SPD | 速度。行動順序に影響 |
| LV | レベル。経験値蓄積で上昇 |

### レベルアップ
- 必要経験値: `100 * (level ^ 1.5)`
- レベルアップ時に全ステータスが成長率に応じて上昇

### タイプ（素質）（Phase 3〜）

キャラクターはタイプ（素質）を持ち、タイプによってステータス成長率が異なる。
タイプは固定（変更不可）だが、スキルは全系統から自由に習得できるため、スキル振りで役割をカスタマイズ可能。

| タイプ | 特徴 |
|--------|------|
| 近接型 | HP・DEF が高い。タンク・前線向き |
| 魔力型 | ATK が非常に高いが HP・DEF が低い。火力特化 |
| 神聖型 | HP・DEF がやや高め。回復・支援向き |
| 敏捷型 | SPD が非常に高い。手数・先制向き |

> 成長率の具体値は [master_data.md](../../data/master_data.md) を参照。

### キャラクターレアリティ（Phase 3〜）

キャラクターは5段階のレアリティを持ち、レアリティに応じてステータスにボーナス倍率が乗算される。

| レアリティ | ステータス倍率 |
|-----------|-------------|
| コモン | ×1.00 |
| アンコモン | ×1.05 |
| レア | ×1.10 |
| エピック | ×1.15 |
| レジェンダリー | ×1.25 |

- 計算: `実効ステータス = 基本ステータス × レアリティ倍率`
- 塔クリア報酬で入手するキャラは全員「レア」固定
- 酒場ガチャではコモン〜レジェンダリーまで排出される
- 詳細は [master_data.md](../../data/master_data.md) §7.2 を参照

### キャラクター獲得（Phase 3〜）

| 方法 | Phase | 詳細 |
|------|-------|------|
| 塔クリア報酬 | Phase 3〜 | 特定の塔・階層をクリアすると新キャラが確定加入 |
| 酒場スカウト | Phase 4〜 | 酒場施設でゴールドを消費してランダム獲得（ガチャ） |

- Phase 3 では新たに3体を塔クリア報酬で確定入手（アカネ・シロナ・ハヤテ）。初期キャラの勇者と合わせて全4タイプが揃う
- Phase 4 以降は酒場ガチャでキャラを無限に追加獲得可能
- 具体的な入手キャラ一覧・ガチャプール・排出率は [master_data.md](../../data/master_data.md) §7 を参照

### 限界突破（Phase 3〜）

同一キャラが重複した場合（Phase 4の酒場ガチャ等）、重複キャラを素材にして**限界突破**を行える。

| 項目 | 仕様 |
|------|------|
| 効果 | 全ステータスに割合ボーナスを乗算（+5%〜+30%） |
| 最大回数 | 5回（各回で効果が累積） |
| 必要素材 | 同一キャラ1体 |

> 限界突破のボーナス量は [master_data.md](../../data/master_data.md) を参照。

## 2.7 パーティ編成（Phase 3〜）

### 概要
最大**4人**のキャラクターでパーティを編成して塔に挑む。

| 項目 | 仕様 |
|------|------|
| パーティ人数 | 最大4人 |
| 前衛/後衛 | なし（全員同列） |
| 行動順 | SPD順（§2.2「行動順ルール」参照） |
| パーティ外キャラ | 控え枠。戦闘に参加せず、EXPも獲得しない |

- パーティメンバーの入れ替えは塔外でいつでも可能
- Phase 1-2 ではキャラ1体のみのため、パーティ編成UIはPhase 3で追加
- 控えキャラのEXP獲得は Phase 4 の訓練場施設で実装

## 2.8 スキルシステム（Phase 3〜）

### 概要
キャラクターはレベルアップで獲得する**スキルポイント（SP）**を消費して、6系統のスキルツリーからスキルを習得する。
スキルには**アクティブスキル**（戦闘中に自動発動）と**パッシブスキル**（常時効果）がある。

### スキル系統（6系統）

| 系統 | テーマ | 主なアクティブ効果 | 主なパッシブ効果 |
|------|--------|------------------|----------------|
| 剣術 | 物理単体攻撃 | 強撃、連続斬り | ATK+%、クリティカル率UP |
| 魔法 | 魔法攻撃（単体/範囲） | ファイアボルト、ファイアストーム | 魔法ダメージ+% |
| 回復 | HP回復・蘇生 | ヒール、全体回復 | 回復量+%、自動回復 |
| 強化 | バフ | ATK強化、全体バフ | バフ持続+、効果量UP |
| 弱体 | デバフ・状態異常 | ATK低下、毒付与 | デバフ持続+、成功率UP |
| 生存術 | 耐久・防御 | 挑発、反撃 | 最大HP+%、被ダメ軽減 |

### スキルポイント（SP）

| 項目 | 仕様 |
|------|------|
| 獲得量 | レベルアップごとに **1 SP** |
| 習得コスト | 系統内の段階で変動（下表参照） |
| 振り直し | **LV × 50G** で全リセット（全SPが返却される） |

| 段階 | 必要SP | 備考 |
|------|--------|------|
| 1段目 | 1 SP | 入門スキル |
| 2段目 | 1 SP | 基本スキル |
| 3段目 | 2 SP | 上級スキル |
| 4段目 | 3 SP | 最上位スキル |

- 同系統の下位スキルを取得していないと上位スキルは習得不可（ツリー構造）
- 系統間の制約なし（異なる系統を自由に組み合わせ可能）

### アクティブスキル

戦闘中に自動発動するスキル。**2枠**にセットしたスキルのみが戦闘で使用される。

| 項目 | 仕様 |
|------|------|
| セット枠 | **2枠** |
| 発動条件 | クールダウン完了時に自動使用 |
| 発動制限 | **キャラ単位**で1ターンに1スキルまで（発動しなければ通常攻撃） |
| 優先度 | 回復 > バフ/デバフ > 攻撃（同優先度はセット枠1を優先） |
| 初期CD | **塔出発時は全スキルCD=0**（即使用可能）。階移行時はCD継続 |
| ターゲット同条件時 | **キャラID順**で決定（行動順と同じタイブレーク） |

| スキル種類 | 発動条件 | クールダウン目安 |
|-----------|---------|--------------|
| 攻撃スキル | CD完了時に通常攻撃の代わりに使用 | 3-5ターン |
| 回復スキル | 味方HP40%以下 + CD完了 | 4-6ターン |
| バフスキル | 戦闘開始時 + CD完了時 | 5-8ターン |
| デバフスキル | CD完了時に使用 | 4-6ターン |

### パッシブスキル

習得するだけで**全て常時有効**。セット枠は不要。

### 挑発スキルの詳細仕様

| 項目 | 仕様 |
|------|------|
| 挑発率 | スキル単体で**最大80%**（スキルレベルで変動: 50%→60%→70%→80%） |
| 非挑発時 | 残りの確率は通常通りランダムターゲット |
| 範囲攻撃 | **挑発無効**（全体攻撃は挑発で吸えない） |
| 複数挑発時 | 合算100%以下: 各挑発者への確率 + 残りランダム |
| | 合算100%超え: 挑発率の比率で按分（例: A:80% + B:60% = 140% → A:57%, B:43%） |

### 蘇生スキル

回復系統の最上位（段階4相当）として**蘇生スキル**が存在する。

| 項目 | 仕様 |
|------|------|
| 効果 | 味方1体をHP30%で復活 |
| CD | 8ターン |
| 自動発動条件 | 味方にHP0のキャラがいる場合 |
| 優先度 | 回復スキルの中で最優先（HP0の味方がいれば蘇生を優先） |

> 具体的なスキル一覧と数値は [skills/](../../data/skills/SKILLS_OVERVIEW.md) を参照。系統別の詳細は各系統ファイルに記載。
