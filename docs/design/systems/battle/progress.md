# ゲーム仕様 — 塔の進行制御

> [battle.md](../battle.md) から分割（[game_spec.md](../../game_spec.md) §2.2）。処理の正は [tech_tower/control.md](../../../tech/detail/tech_tower/control.md)・[tech_tower/progress.md](../../../tech/detail/tech_tower/progress.md)。

## 進行モード

塔選択時に以下のモードを選択できる:

| モード | 動作 |
|--------|------|
| **自動周回**（デフォルト） | 目標階クリア後、1階から自動で再突入する |
| **クリア後停止** | 目標階クリア後、戦闘を停止する（報酬確認・装備変更などに便利） |

- 進行中にいつでもモードを切り替え可能
- 進行中に **「リタイア」** を選択すると、その時点で**即時に**撤退する（戦闘の途中でも成立する。討伐しきっていない敵の報酬は得られない。処理の正は [tech_tower/control.md](../../../tech/detail/tech_tower/control.md) §11）
- リタイア時、それまでに獲得した報酬は保持される（没収なし）
- オフライン中は選択中のモードに従って自動処理される

## 目標階設定

- 塔に挑戦する前に **目標階** を設定できる
- 選択可能範囲: 1階 〜 **その塔の到達済み最高階 + 1**（未挑戦の塔は1階のみ）
  - 「到達済み最高階」は**塔ごとに個別管理**する（他の塔での到達階は影響しない）
  - 上限が `+1` なのは、新しい階を1階ずつ開拓できるようにするため。上限を到達済み最高階そのものにすると次の階へ進む手段がなくなる
  - 塔の総階数を超える値は設定できない（上限は `min(到達済み最高階 + 1, 総階数)`）
- **上限追従**: 目標階が上限と一致している状態で新しい階をクリアすると、目標階を自動的に +1 する。放置中でも手動操作なしで開拓が進む
  - 目標階を上限より低く設定している場合は追従しない（プレイヤーの意図した周回階を維持する）
- 目標階に到達しクリアすると、進行モードに応じてループまたは停止する
- 未到達の階（到達済み最高階 + 2 以上）は目標に設定できない

## 撤退条件

塔選択時に以下の撤退条件を設定できる（複数同時に有効化可能）:

| 条件 | 動作 |
|------|------|
| **目標階到達**（デフォルト） | 目標階をクリアしたら撤退し、進行モードに従う |
| **HP閾値撤退** | パーティのHPが設定割合（例: 30%）未満になったら、次の階に進まず撤退する |

- **HP閾値のチェックタイミング**: 各階の戦闘が完了した後に判定する。閾値未満であれば次の階に進まず撤退する（その階の報酬は獲得済み。閾値0は本条件の無効化。判定式は [tech_tower/progress.md](../../../tech/detail/tech_tower/progress.md) §9）
- HP閾値撤退が発動した場合、それまでに獲得した報酬は保持される
- 撤退後、自動周回モードなら**塔内で**1階から再スタートする（塔外へは出ない）。クリア後停止モードなら塔外へ出る
- どの撤退条件も設定しない場合は、目標階到達のみが撤退トリガーとなる
- **全滅時は常に強制撤退**（撤退条件とは独立。詳細は「全滅時の処理」）

## 全滅時の処理

味方パーティが全滅（全員HP 0）した場合、**常に塔から強制撤退し、戦闘を停止** する（自動周回モードであっても再スタートしない）。
プレイヤーが手動で再出発する必要がある。

**全滅ペナルティ:**
1. **経験値ロスト** — 現在レベル内の蓄積経験値の **50%** を失う（レベルダウンはしない）
2. **ゴールドロスト** — 今回の塔探索中に取得したゴールドを **すべて失う**（塔に入る前の所持ゴールドは影響なし）
3. **アイテムロスト** — 今回の塔探索中に取得したドロップアイテムを **すべて失う**（塔に入る前の所持品は影響なし）

> **設計意図**: 全滅にリスクを持たせることで、目標階設定・撤退条件の戦略的な選択を促す。高い階を狙えば報酬は大きいが、全滅リスクも高まるリスク・リワードのバランス。
