## 認証画面（Phase 2〜）

### ログイン画面
```
+---------------------------------------------+
|              [ゲームタイトルロゴ]           |
|                                             |
|  メールアドレス: [________________]         |
|  パスワード:     [________________]         |
|                                             |
|  [        ログイン        ]                 |
|                                             |
|  [   Googleでログイン   ]                   |
|                                             |
|  [   ゲストでプレイ     ]                   |
|                                             |
|  アカウント登録はこちら   パスワードを忘れた|
+---------------------------------------------+
```

### 登録タブ

独立画面ではなく**ログイン画面内のタブ**として表示する（UXの観点で統合。`/register` へ直接アクセスした場合も同タブを開く）。登録直後は確認メール送信の完了を待たず、即ホームへ遷移する（未確認でもプレイ可）。

```
+------------------------------------------------+
|              アカウント登録                    |
|                                                |
|  メールアドレス: [________________]            |
|  パスワード:     [________________]  ※8文字以上|
|  パスワード確認: [________________]            |
|                                                |
|  [        登録する        ]                    |
|                                                |
|  [   Googleで登録   ]                          |
|                                                |
|  ログインはこちら                              |
+------------------------------------------------+
```

### ゲスト→本登録バナー
ゲストプレイ中、ゲーム画面上部にアカウント登録を促すバナーを常時表示。

```
+------------------------------------------------------+
| [!] データを守るためにアカウント登録しましょう [登録]|
+------------------------------------------------------+
|  （通常のゲーム画面）                                |
|  ...                                                 |
+------------------------------------------------------+
```

- バナーは非表示にできない（ゲストプレイ中は常時表示）
- [登録] ボタンで本登録フォーム（登録タブと同一UI）を開く。ゲストデータを引き継ぐため `POST /api/auth/link-account` を呼ぶ（新規登録ではない。[api_sequence/auth.md](../../../diagrams/api_sequence/auth.md) §14）
- 本登録完了後にバナーは自動で消える

## チュートリアル（Phase 1〜）

インラインヒント方式（ツールチップ）で初回プレイ時にガイドを表示する。モーダルや強制的な操作制限は行わない。

### ヒント一覧

| # | 表示タイミング | 内容 |
|---|-------------|------|
| 1 | 初回ログイン時 | 「冒険者が自動で塔を探索します。放置しても進行します！」 |
| 2 | 初回レベルアップ時 | 「レベルアップでステータスが上昇しました！より強い敵に挑めます」 |
| 3 | HP50%以下初到達時 | 「HPが減ってきました。ポーションは自動で使用されます」 |
| 4 | 初回装備ドロップ時（Phase 2〜） | 「装備を入手しました！装備画面で装着できます」 |

- ヒントは1回限り表示（閉じたら再表示しない）
- 初回ログイン時にHPポーション×5を自動付与
