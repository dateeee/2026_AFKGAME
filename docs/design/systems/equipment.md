# ゲーム仕様 — 装備・素材生産

> [game_spec.md](../game_spec.md) §2.4 / §2.10。数値定義は [master_data.md](../../data/master_data.md)。

## 2.4 装備システム（Phase 2〜）

### 装備スロット（9スロット）
| スロット | 説明 |
|---------|------|
| 武器 | 攻撃に使用。片手武器と両手武器がある |
| 盾 | 片手武器装備時のみ装備可能。両手武器装備時は使用不可 |
| 頭 | 兜・帽子など |
| 胴体 | 鎧・ローブなど |
| 腕 | 篭手・手袋など |
| 腰 | ベルト・サッシュなど |
| 足 | ブーツ・サンダルなど |
| 耳 | イヤリング・ピアス・ペンダントなど |
| 指輪 | 指輪・お守りなど |

### 武器分類
| 分類 | 武器種 | 盾 | 備考 |
|------|--------|-----|------|
| 片手武器 | 剣、短剣、メイス | 装備可 | バランス型 |
| 両手武器 | 大剣、槍、弓、杖 | 装備不可 | 高ATKだが盾なし |

### 装備ステータス
- 各装備にはATK/DEF/HP/SPDのいずれか1つ以上がランダムに付与される
- スロットによる制限はなし（頭装備にATKが付くこともある）
- 付与されるステータスの数はレアリティに依存
- タイプ制限なし（どのタイプでもすべての装備を装備可能）

### レアリティ
| レアリティ | 色 | ステータス倍率 | 付与ステータス数 |
|-----------|-----|---------------|----------------|
| コモン | 白 | x1.0 | 1-2 |
| アンコモン | 緑 | x1.3 | 2 |
| レア | 青 | x1.6 | 2-3 |
| エピック | 紫 | x2.0 | 3 |
| レジェンダリー | 橙 | x2.5 | 4（全種確定） |

### レアリティ出現率（階層依存）
基本確率（1F時点）:

| レアリティ | 基本確率 |
|-----------|---------|
| コモン | 60.5% |
| アンコモン | 25% |
| レア | 10% |
| エピック | 4% |
| レジェンダリー | 0.5% |

- 階層補正: `補正後確率 = 基本確率 × (1 + 0.05 × 階層)`（上位ほど恩恵大）
- コモン確率は残余（100% − 他の合計）で自動調整

### ドロップ率
- 通常敵: 各敵に装備ドロップ率を設定（10-20%程度）
- ボス敵: 高確率で装備をドロップ（50-100%。終盤の塔ほど高く、最終塔のボスは確定ドロップ）
- ドロップ時にスロット種・レアリティ・ステータスをランダム決定

### 装備の基礎ステータス値
装備レベル（＝ドロップ元の敵LV相当）に応じた基礎値:
- `基礎値 = floor(敵LV × 1.5 + 2)`
- `実効値 = 基礎値 × レアリティ倍率`
- ステータス種による補正: ATK=×1.0、DEF=×0.7、HP=×5.0、SPD=×0.3

### 売却価格
- `売却価格 = 5 × レアリティ倍率 × 装備レベル`（端数切り捨て）
- 意図的に安く設定（装備は将来の強化素材として保持推奨）
- ゴールド収入源としては換金アイテム（銅貨の袋等）を使用

### 入手方法
| 方法 | Phase | 詳細 |
|------|-------|------|
| 敵ドロップ | Phase 2〜 | 塔内の敵を倒した時にランダムドロップ |
| 製作 | Phase 4〜 | 鍛冶屋で素材を消費して製作 |

### HP吸収装備（Phase 2〜）

通常装備とは別に、**HP吸収効果を持つ特殊装備**が存在する。
攻撃時に与えたダメージの一定割合をHPとして回復する。

| 項目 | 仕様 |
|------|------|
| 分類 | 特殊装備カテゴリ（通常装備とは別に個別定義） |
| 吸収率 | 3〜8%（与ダメージに対する割合、装備ごとに固定） |
| 対象スロット | 全スロットに登場しうる |
| 合計上限 | なし（複数装備で積み重ね可能） |
| 回復計算 | `floor(与ダメージ × 吸収率)` を攻撃時に即時HP回復 |
| 出現条件 | 森の塔（塔2）10F以降の敵からドロップ開始 |
| ショップ販売 | なし（ドロップ専用） |

- 入手方法: 敵ドロップ（Phase 2〜） / 鍛冶屋製作（Phase 4〜）
- 低階層では補助的な回復手段（与ダメ30 × 5% = 1.5HP程度）
- ポーションの代替ではなく、ポーション消費を緩やかに抑える位置づけ
- 具体的な吸収装備の一覧は [master_data.md](../../data/master_data.md) を参照

> **設計意図**: 序盤〜中盤はポーション中心のHP管理。吸収装備を入手することで継戦力が徐々に向上し、高階層への挑戦を後押しする。

### 装備強化（Phase 4〜）

鍛冶屋施設で装備を強化できる。強化は**段階方式**で、+1ずつ確定成功する（失敗なし）。

| 項目 | 仕様 |
|------|------|
| 強化方式 | +1ずつ段階強化。確定成功（失敗なし） |
| 強化上限 | 鍛冶屋LVに依存（LV1: +1、LV5: +5、LV10: +10） |
| 強化計算 | `強化後ステータス = 元のステータス + (強化値 × 基礎値の10%)` |
| 消費素材 | 強化石 + ゴールド（1回ごとに消費） |
| コスト倍率 | 鍛冶屋LVが上がるとコスト割引（LV1: x1.0 → LV10: x0.6） |

- 強化値は装備ごとに個別管理（+3の剣、+5の鎧など）
- 強化コストの詳細は [master_data.md](../../data/master_data.md) を参照

## 2.10 素材・生産システム（Phase 4〜）

### 素材の種類

| ID | 名前 | 主な用途 | 出現帯 |
|----|------|---------|--------|
| `enhance_stone` | 強化石 | 装備強化・施設建設 | 全塔 |
| `magic_crystal` | 魔法の結晶 | 装備製作・施設建設 | ダンジョン2〜 |
| `rare_ore` | 希少鉱石 | 高レア装備製作・施設LV上げ | 中盤〜終盤の塔 |
| `ancient_fragment` | 古代の欠片 | レジェンダリー製作・施設LV8〜10 | 終盤の塔・ボス |

### 素材の入手方法

| 入手方法 | 詳細 |
|---------|------|
| 敵ドロップ | 全塔の敵が強化石をドロップ。上位素材は高階層・ボスのみ |
| 装備分解 | 鍛冶屋で不要な装備を分解して素材に変換 |

### 装備分解

鍛冶屋で不要な装備を素材に変換する。

| レアリティ | 強化石 | 魔法の結晶 | 希少鉱石 | 古代の欠片 |
|-----------|--------|----------|---------|----------|
| コモン | 1 | - | - | - |
| アンコモン | 2 | - | - | - |
| レア | 3 | 1 | - | - |
| エピック | 5 | 2 | 1 | - |
| レジェンダリー | 10 | 5 | 3 | 1 |

### 装備製作

鍛冶屋で素材を消費してランダム装備を製作する。スロット・ステータスはランダム決定（ドロップと同じ仕組み）。
鍛冶屋LVが製作可能ランクの上限を決める。

| 製作ランク | 必要素材 | ゴールド | 結果 |
|-----------|---------|---------|------|
| ランク1（コモン） | 強化石×5 | 500G | コモン装備1個 |
| ランク2（アンコモン） | 強化石×10, 魔法の結晶×3 | 2,000G | アンコモン装備1個 |
| ランク3（レア） | 強化石×20, 魔法の結晶×8, 希少鉱石×2 | 5,000G | レア装備1個 |
| ランク4（エピック） | 強化石×30, 魔法の結晶×15, 希少鉱石×5 | 15,000G | エピック装備1個 |
| ランク5（レジェンダリー） | 強化石×100, 魔法の結晶×50, 希少鉱石×20, 古代の欠片×10 | 500,000G | レジェンダリー装備1個 |

> **設計意図**: レジェンダリー装備の製作は極端に高コスト（50万G + 大量素材）に設定。ドロップで偶然入手するか、長期的な素材蓄積で確実に製作するかの選択肢を提供。
