# ゲーム仕様 — UI構成

> [game_spec.md](../game_spec.md) §3。画面遷移は [screen_transition.md](../../../diagrams/screen_transition.md)。

## 描画方針
- **すべてDOM（HTML/CSS）で構成**。Canvasは使用しない
- 戦闘描写・キャラクターアニメーションなし。**テキストログのみで戦闘を表現**
- アイテム・装備・レアリティ等には**小さなアイコン画像**を使用してよい
- HPバー・経験値バーなどのゲージ表現はCSS（`<div>` + `width%`）で実装

## ブラウザ対応範囲・レスポンシブ設計

| 項目 | 仕様 |
|------|------|
| 対応ブラウザ | Chrome, Safari, Firefox, Edge（各最新2バージョン） |
| デザイン方針 | モバイルファースト・レスポンシブ |
| ブレークポイント | 768px（以下: モバイル、以上: PC） |
| 最小対応幅 | 320px（iPhone SE相当） |
| レイアウト | PC: 2カラム / モバイル: 1カラム（縦積み） |
| タッチ操作 | タップ対応（ホバー依存のUIは避ける） |
| PWA | Phase 1 では対応しない（将来検討） |

- 大きな数値（ゴールド等）は**短縮表記**で表示（詳細ルールは §3「数値表示フォーマット」参照）

## アクセシビリティ

| 項目 | 方針 |
|------|------|
| HTML | セマンティックHTML要素を使用（`<button>`, `<nav>`, `<main>`, 見出しタグ等） |
| キーボード操作 | Tab移動・Enter実行で全機能にアクセス可能 |
| 色非依存 | 色だけに依存しない情報表示（テキストラベル・アイコンを併用） |
| WCAG準拠 | 明示的に定めない（ベストエフォート） |

- テキストベースUIのため、スクリーンリーダーとの親和性は自然に高い

## チュートリアル（Phase 1〜）

インラインヒント方式（ツールチップ）で初回プレイ時にガイドを表示する。モーダルや強制的な操作制限は行わない。

### ヒント一覧

| # | 表示タイミング | 内容 |
|---|-------------|------|
| 1 | 初回ログイン時 | 「冒険者が自動で塔を探索します。放置しても進行します！」 |
| 2 | 初回レベルアップ時 | 「レベルアップでステータスが上昇しました！より強い敵に挑めます」 |
| 3 | HP50%以下初到達時 | 「HPが減ってきました。ポーションは自動で使用されます」 |
| 4 | 初回装備ドロップ時（Phase 2〜） | 「装備を入手しました！装備画面で装着できます」 |

- ヒントは1回限り表示（閉じたら再表示しない）
- 初回ログイン時にHPポーション×5を自動付与

## 通知システム（Phase 1〜）

3種類の通知レベルを使い分ける。

| 種別 | 表示方法 | 用途例 | 消去 |
|------|---------|--------|------|
| ログ内通知 | 戦闘ログ内にインライン表示 | 敵撃破、ドロップ獲得、階層移動 | 自動（ログスクロール） |
| トースト | 画面上部に一時表示 | レベルアップ、装備獲得、実績解除 | 3秒で自動消去 |
| モーダル | 画面中央にダイアログ表示 | ボス撃破、新キャラ加入、重要な警告 | 手動で閉じる |

- トーストは最大3件まで同時表示（4件目以降はキュー待ち）
- モーダルは同時に1件のみ表示

### 通知キューのルール

- 表示待ちキューは**FIFO**（先入れ先出し）。通常通知に優先度の概念は設けない
- 待ちキューの上限は**10件**。超過時は最も古い**待機中**の通知を破棄する（表示中の3件は破棄しない）
- **エラー通知**（通信エラー等）は例外としてキュー先頭に割り込む。表示枠が埋まっている場合は最も古い表示中トーストを押し出して即時表示する
- エラー通知は設定「トースト通知: OFF」でも表示する（OFFの対象は通常トーストのみ）

## 装備管理UI（Phase 2〜）

### 装備比較
- 装備アイテムにカーソルを合わせると（モバイルはタップで）、現在装備中のアイテムとの比較ポップアップを表示
- 差分を色分け表示（上昇: 緑、低下: 赤）

### ソート・フィルター
- ソート: レアリティ / 装備レベル / ステータス種別
- フィルター: レアリティ / スロット種別 / 装備可否

### 一括売却
- レアリティを指定して一括売却（確認ダイアログあり）
- ロック機能: 売却から保護（ロック中のアイテムは一括売却対象外）

### 自動装備
- 「最強装備」ボタンで全スロットに最もステータスが高い装備を自動装着
- 評価基準: 各スロットについて `ATK + DEF + HP/5 + SPD` の合計値が最大の装備を選択

## 設定画面（Phase 1〜）

| 設定項目 | デフォルト値 | 説明 | Phase |
|---------|-----------|------|-------|
| ポーション自動使用閾値 | 30% | HP何%以下で自動使用するか（10%〜50%、10%刻み） | 1 |
| 戦闘ログ表示件数 | 50件 | ログの最大表示件数（20/50/100）。上限はDB保存件数100件（[non_functional_requirements.md §2](../non_functional_requirements.md)） | 1 |
| トースト通知 | ON | トースト通知の表示ON/OFF | 1 |
| 自動売却レアリティ | OFF | 指定レアリティ以下の装備を自動売却（OFF/コモン/アンコモン） | 2 |

- 設定はサーバー側に保存（ゲーム状態JSONの settings フィールド）
- ゲスト時もサーバーに保存される

## 数値表示フォーマット（Phase 1〜）

大きな数値（ゴールド・EXP・ダメージ等）は**短縮表記**で表示する。1,000以上はすべて短縮し、生表示との併用はしない。

| 値の範囲 | 単位 | 例 |
|----------|------|-----|
| 0 〜 999 | そのまま表示 | 999 |
| 10^3 〜 | K | 2,500 → 2.5K / 999,999 → 999.9K |
| 10^6 〜 | M | 1,500,000 → 1.5M |
| 10^9 〜 | B | 2,300,000,000 → 2.3B |
| 10^12 〜 | T | 1.0T |
| 10^15 〜 | Qa | 1.0Qa |
| 10^18 〜 | Qi | 9.2Qi（ゴールド上限 ≒ 9.2Qi） |

- 小数は**1桁固定・切り捨て**（例: 999,999 → 999.9K。1.0M に繰り上げない）
- 単位の境界では常に下位単位を優先（1,000,000 未満は K 表記のまま）
- 実装は `src/utils/format.ts` の共通ユーティリティに集約する（[tech_spec.md §3](../../tech/tech_spec.md) 参照）
