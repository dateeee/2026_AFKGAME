## 2.11 ボスラッシュ（Phase 5〜）

### 概要
既存のボスが次々に登場する無限ウェーブ制のエンドコンテンツ。挑戦制限なし。
全滅するまで戦い続け、最高到達ウェーブ数をサーバーランキングに登録する。

### ウェーブ構成

| ウェーブ帯 | 出現する敵 | 強化倍率 |
|-----------|----------|---------|
| Wave 1〜5 | 通常敵（各塔の中〜強めの敵） | ×1.0 |
| Wave 6〜10 | 既存ボス（ゴブリンキング→ベヒーモス→獣の塔ボス〈キングハイドラ〉→毒沼の塔ボス〈ポイズンドレイク〉→業火の塔ボス〈バアル〉の順） | ×1.0 |
| Wave 11〜 | ボス強化版（Wave11以降、1ウェーブごとに全ステータス+10%） | ×1.1〜 |

- 5ウェーブごとに**HP 10%回復**
- **ポーション使用可**（通常通り所持数消費）
- **各ウェーブ開始時にスキルCDを全リセット、バフ/デバフ/状態異常をクリア**（クリーンな状態で開始）
- ボスラッシュ中は通常の塔探索は停止（同時進行不可）
- オフライン進行: あり（tick処理で進行、全滅で自動終了し累積報酬確定）

### 報酬体系

**累積報酬（毎ウェーブ）:**
- 各ウェーブ突破ごとにゴールド＋EXPを獲得（通常塔の50%相当、仮置き）
- 全滅時も累積分は没収なし（確定取得）

**マイルストーン報酬（初回到達時のみ）:**

| 到達ウェーブ | 初回ボーナス |
|------------|-----------|
| Wave 5 | 強化石×10 |
| Wave 10 | 魔法の結晶×5 |
| Wave 15 | 希少鉱石×3 |
| Wave 20 | 古代の欠片×1 |
| Wave 25 | 古代の欠片×2 |
| Wave 30 | 古代の欠片×3 + レジェンダリー装備×1 |
| Wave 40 | 古代の欠片×5 + レジェンダリー装備×1 |
| Wave 50 | 古代の欠片×8 + レジェンダリー装備×2 |
| Wave 60 | 古代の欠片×12 + レジェンダリー装備×3 |
| Wave 70+ | 以降10ウェーブごとに古代の欠片+5、レジェンダリー装備+1 |

### ランキング

| 項目 | 仕様 |
|------|------|
| 種別 | サーバーランキング（認証ユーザー対象、全プレイヤー共通） |
| 順位指標 | 最高到達ウェーブ数（多いほど上位） |
| タイブレーク | 同ウェーブの場合、全滅時の残HP合計が高いほど上位 |
| 自己ベスト | 挑戦ごとに自動更新。過去の最高記録を保持 |
| ゲスト時 | ランキング閲覧のみ可能（登録には認証が必要） |

> **設計意図**: 挑戦制限なしで何度でも挑戦でき、サーバーランキングで他プレイヤーと記録を競う。チート対策はサーバー権威（tick処理）で担保。

## 2.12 転生システム（プレステージ）（Phase 5〜）

### 概要
特定のキャラクターがLV9999に到達すると、そのキャラクターのみ**転生**を選択できる。
転生するとキャラのLVがリセットされる代わりに**転生ポイント**を獲得し、そのキャラクター専用の恒久ボーナスに投資できる。

### 解放条件
- **条件**: そのキャラクターがLV9999に到達
- **単位**: キャラクター個別（1体がLV9999になれば、その1体だけ転生可能。他のキャラは影響なし）
- 転生は任意（LV9999のままプレイを続けることも可能）
- **オフライン中の転生**: 発生しない。オフライン計算中にLV9999へ到達したキャラはLV9999で成長停止し、超過分のEXPは切り捨てる。復帰後にプレイヤーが手動で転生する（[tech_battle.md §4](../../tech/tech_battle.md) 参照）

### リセット範囲

| 項目 | 転生後 |
|------|-------|
| レベル | LV1 にリセット |
| 経験値 | 0 にリセット |
| スキルポイント（SP） | 全返還（振り直し無料で再配分可能） |
| 装備 | **そのまま保持** |
| 限界突破回数 | **そのまま保持** |
| 転生回数（キャラごと管理） | +1 カウント |

- 他のキャラクター・施設・ゴールド・素材・アイテム在庫はすべて影響なし

### 転生ポイント

| 項目 | 仕様 |
|------|------|
| 獲得量 | 転生1回につき **10pt**（仮置き） |
| 管理単位 | **そのキャラクター専用**（他のキャラには引き継がれない） |
| 投資先 | 下記ボーナステーブルから自由に選択 |
| 振り直し | ゴールドを消費して全リセット可能（コストは [master_data.md §16](../../data/master_data.md) 参照） |

### 転生ボーナス（キャラクター個別）

| ボーナス | 効果/pt | 上限 |
|---------|--------|------|
| HP強化 | +1% | 50pt（+50%） |
| ATK強化 | +1% | 50pt（+50%） |
| DEF強化 | +1% | 50pt（+50%） |
| SPD強化 | +1% | 50pt（+50%） |
| EXP獲得ボーナス | +2% | 30pt（+60%） |
| スキルダメージ強化 | +1% | 30pt（+30%） |

- ボーナスは**そのキャラクターにのみ適用**（パーティ全体には影響しない）
- 計算: `実効ステータス = 通常計算値 × (1 + 転生ボーナス%)`
- 転生回数に上限はない（LV9999→転生→LV9999→転生... を繰り返せる）

> **設計意図**: 1体のキャラを繰り返し育てる「推しキャラやりこみ」要素。転生を重ねるほど強くなり、特定キャラへの愛着形成につながる。

## 2.13 イベントダンジョン（Phase 5〜）

### 概要
通常の塔とは異なる特殊なダンジョン。常設コンテンツとして複数種を常時解放する。
固定難易度3段階で、プレイヤーが自分の実力に合った難易度を選択して挑む。

### 開催・解放方針

| 項目 | 仕様 |
|------|------|
| 運営方式 | **常設**（期間限定ではなく常時プレイ可能） |
| 解放数 | 3種を常時解放 |
| 挑戦制限 | なし（何度でも挑戦可能） |

### 難易度設定

| 難易度 | 対象レベル目安 | 報酬倍率 |
|--------|-------------|-------------|
| 初級 | LV1〜30 | ×1.0 |
| 中級 | LV25〜60 | ×2.0 |
| 上級 | LV50〜 | ×4.0 |

- 難易度はプレイヤーが自由に選択。未解放の難易度はない（最初から全難易度選択可）
- 敵のステータスは各難易度に対して固定値で定義（LVスケーリングなし）
- 報酬倍率はゴールド・EXP・素材ドロップ量に適用

### 報酬

- 通常報酬のみ（ゴールド・EXP・素材・装備ドロップ）
- 限定装備・限定キャラなし
### イベントダンジョン一覧

| 名称 | テーマ | 特徴 | 主な報酬 |
|------|--------|------|---------|
| 試練の迷宮 | 戦闘特化 | 強敵連戦、ボスラッシュ風 | 強化石・魔法の結晶（高効率） |
| 宝物庫 | 報酬特化 | 敵は弱めだがドロップ率UP | ゴールド・装備ドロップ（高効率） |
| 修練場 | 経験値特化 | EXP大量獲得、低報酬 | EXP（高効率）、素材は少なめ |

- 各ダンジョンとも初級・中級・上級の3難易度
- 具体的な敵構成・報酬テーブルは [master_data.md](../../data/master_data.md) で後日定義

> **設計意図**: 通常の塔とは異なる敵・ステージを楽しむバリエーションコンテンツ。エンドコンテンツとして高難易度でやりこみ素材を効率よく集める手段にもなる。目的別（素材・ゴールド・EXP）に使い分けられる。
