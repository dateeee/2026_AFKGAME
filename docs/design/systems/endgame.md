# ゲーム仕様 — エンドコンテンツ（Phase 5〜）

> [game_spec.md](../game_spec.md) §2.11 / §2.12 / §2.13。数値定義は [master_data.md](../../data/master_data.md)。

## 2.11 ボスラッシュ（Phase 5〜）

### 概要
既存のボスが次々に登場する無限ウェーブ制のエンドコンテンツ。挑戦制限なし。
全滅するまで戦い続け、最高到達ウェーブ数をサーバーランキングに登録する。

### ウェーブ構成

| ウェーブ帯 | 出現する敵 | 強化倍率 |
|-----------|----------|---------|
| Wave 1〜5 | 通常敵（各塔の中〜強めの敵） | ×1.0 |
| Wave 6〜10 | 既存ボス（ゴブリンキング→ベヒーモス→獣の塔ボス〈キングハイドラ〉→毒沼の塔ボス〈ポイズンドレイク〉→業火の塔ボス〈バアル〉の順） | ×1.0 |
| Wave 11〜 | ボス強化版（Wave11以降、1ウェーブごとに全ステータス+10%） | ×1.1〜 |

- 5ウェーブごとに**HP 10%回復**
- **ポーション使用可**（通常通り所持数消費）
- **各ウェーブ開始時にスキルCDを全リセット、バフ/デバフ/状態異常をクリア**（クリーンな状態で開始）
- ボスラッシュ中は通常の塔探索は停止（同時進行不可）
- オフライン進行: あり（tick処理で進行、全滅で自動終了し累積報酬確定）

### 報酬体系

**累積報酬（毎ウェーブ）:**
- 各ウェーブ突破ごとにゴールド＋EXPを獲得（通常塔の50%相当、仮置き）
- 全滅時も累積分は没収なし（確定取得）

**マイルストーン報酬（初回到達時のみ）:**

Wave 5 から10ウェーブ刻みで素材・レジェンダリー装備を付与する。2回目以降の到達では付与しない（累積報酬のみ）。**報酬内容は [master/endgame.md §15.2](../../data/master/endgame.md) が正**（本書では定義しない）。

### ランキング

| 項目 | 仕様 |
|------|------|
| 種別 | サーバーランキング（認証ユーザー対象、全プレイヤー共通） |
| 順位指標 | 最高到達ウェーブ数（多いほど上位） |
| タイブレーク | 同ウェーブの場合、全滅時の残HP合計が高いほど上位 |
| 自己ベスト | 挑戦ごとに自動更新。過去の最高記録を保持 |
| ゲスト時 | ランキング閲覧のみ可能（登録には認証が必要） |

> **設計意図**: 挑戦制限なしで何度でも挑戦でき、サーバーランキングで他プレイヤーと記録を競う。チート対策はサーバー権威（tick処理）で担保。

## 2.12 転生システム（プレステージ）（Phase 5〜）

### 概要
特定のキャラクターがLV9999に到達すると、そのキャラクターのみ**転生**を選択できる。
転生するとキャラのLVがリセットされる代わりに**転生ポイント**を獲得し、そのキャラクター専用の恒久ボーナスに投資できる。

### 解放条件
- **条件**: そのキャラクターがLV9999に到達
- **単位**: キャラクター個別（1体がLV9999になれば、その1体だけ転生可能。他のキャラは影響なし）
- 転生は任意（LV9999のままプレイを続けることも可能）
- **オフライン中の転生**: 発生しない。オフライン計算中にLV9999へ到達したキャラはLV9999で成長停止し、超過分のEXPは切り捨てる。復帰後にプレイヤーが手動で転生する（[tech_battle.md §4](../../tech/tech_battle.md) 参照）

### リセット範囲

| 項目 | 転生後 |
|------|-------|
| レベル | LV1 にリセット |
| 経験値 | 0 にリセット |
| スキルポイント（SP） | 全返還（振り直し無料で再配分可能） |
| 装備 | **そのまま保持** |
| 限界突破回数 | **そのまま保持** |
| 転生回数（キャラごと管理） | +1 カウント |

- 他のキャラクター・施設・ゴールド・素材・アイテム在庫はすべて影響なし

### 転生ポイント

| 項目 | 仕様 |
|------|------|
| 獲得量 | 転生1回につき **10pt**（仮置き） |
| 管理単位 | **そのキャラクター専用**（他のキャラには引き継がれない） |
| 投資先 | 下記ボーナステーブルから自由に選択 |
| 振り直し | ゴールドを消費して全リセット可能（コストは [master_data.md §16](../../data/master_data.md) 参照） |

### 転生ボーナス（キャラクター個別）

HP／ATK／DEF／SPD／EXP獲得／スキルダメージの6種に、獲得した転生ポイントを自由に配分できる。**効果量・投資上限は [master/endgame.md §16.1](../../data/master/endgame.md) が正**（本書では定義しない）。

- ボーナスは**そのキャラクターにのみ適用**（パーティ全体には影響しない）
- 計算: `実効ステータス = 通常計算値 × (1 + 転生ボーナス%)`
- 転生回数に上限はない（LV9999→転生→LV9999→転生... を繰り返せる）

> **設計意図**: 1体のキャラを繰り返し育てる「推しキャラやりこみ」要素。転生を重ねるほど強くなり、特定キャラへの愛着形成につながる。

## 2.13 イベントダンジョン（Phase 5〜）

### 概要
通常の塔とは異なる特殊なダンジョン。常設コンテンツとして複数種を常時解放する。
固定難易度3段階で、プレイヤーが自分の実力に合った難易度を選択して挑む。

### 開催・解放方針

| 項目 | 仕様 |
|------|------|
| 運営方式 | **常設**（期間限定ではなく常時プレイ可能） |
| 解放数 | 3種を常時解放 |
| 挑戦制限 | なし（何度でも挑戦可能） |

### 進行モデル

通常の塔と**同じ階層制**を用いる。専用の進行ルールは設けない。

| 項目 | 仕様 |
|------|------|
| 階層数 | 1ダンジョンあたり **10階**（難易度によらず共通） |
| クリア条件 | 10階のボスを撃破 |
| クリア後 | 何度でも再挑戦できる。周回モード（`auto_repeat` / `stop_on_clear`）は塔と同じ |
| 目標階・リタイア | 塔と同じ（目標階の上限は `min(そのダンジョンの到達済み最高階 + 1, 10)`） |
| tick・オフライン | 塔と同じハイブリッドtick制。オフライン中も進行する |

- 難易度は入場時に選択し、探索中は変更できない。難易度ごとに到達済み最高階を個別管理する
- 塔の進行ルールを再利用するため、入退場の実現方式も `/api/tower/*` の流用を基本とする（確定は基本設計。[tech_api.md](../../tech/tech_api.md)）

### 難易度設定

| 難易度 | 対象レベル目安 | 報酬倍率 |
|--------|-------------|-------------|
| 初級 | LV1〜30 | ×1.0 |
| 中級 | LV25〜60 | ×2.0 |
| 上級 | LV50〜 | ×4.0 |

- 難易度はプレイヤーが自由に選択。未解放の難易度はない（最初から全難易度選択可）
- 敵のステータスは各難易度に対して固定値で定義（LVスケーリングなし）
- 報酬倍率はゴールド・EXP・素材ドロップ量に適用

### 報酬

- 通常報酬のみ（ゴールド・EXP・素材・装備ドロップ）
- 限定装備・限定キャラなし
### イベントダンジョン一覧

| 名称 | テーマ | 特徴 | 主な報酬 |
|------|--------|------|---------|
| 試練の迷宮 | 戦闘特化 | 強敵連戦、ボスラッシュ風 | 強化石・魔法の結晶（高効率） |
| 宝物庫 | 報酬特化 | 敵は弱めだがドロップ率UP | ゴールド・装備ドロップ（高効率） |
| 修練場 | 経験値特化 | EXP大量獲得、低報酬 | EXP（高効率）、素材は少なめ |

- 各ダンジョンとも初級・中級・上級の3難易度

### 敵プールの調達

| 対象 | 調達方針 |
|------|---------|
| 1〜9階の雑魚 | 塔1〜10 の**既存敵を流用**する。難易度ごとに固定ステータスで再定義し、元の塔のLVスケーリングは引き継がない |
| 10階のボス | **イベント専用**を新規定義する。3ダンジョン × 3難易度 = **9体** |

- 雑魚の選定は各ダンジョンのテーマに合わせる（試練の迷宮＝強敵寄り、宝物庫＝弱敵寄り、修練場＝低LV帯中心）
- 具体的なステータス値・報酬テーブルは Phase 5 の詳細設計で [master_data.md](../../data/master_data.md) へ定義する

> **設計意図**: 通常の塔とは異なる敵・ステージを楽しむバリエーションコンテンツ。エンドコンテンツとして高難易度でやりこみ素材を効率よく集める手段にもなる。目的別（素材・ゴールド・EXP）に使い分けられる。

## 2.14 深淵の塔（Phase 5〜）

### 概要
階数に上限のない**無限塔**。通常の塔（001〜010）は推奨LV155 で打ち止めになるため、**LV155〜9999 を埋める常設の放置コンテンツ**として位置づける。
既存の塔システム（目標階・進行モード・撤退条件・オフライン進行）をそのまま使用し、専用の進行ルールは持たない。

### 基本仕様

| 項目 | 仕様 |
|------|------|
| 塔ID | `abyss_tower` |
| ダンジョン | 終焉のダンジョン |
| 解放条件 | 天空の塔クリア（天界の覇王討伐） |
| 階数 | **無限**（総階数の上限なし） |
| 通常敵 | 既存全塔の通常敵から階層帯別プールで抽選 |
| ボス階 | **10階ごと**（10F, 20F, ...）に既存ボスの強化版が出現 |
| 目標階の上限 | §2.2 の共通ルールを適用。総階数が無いため `到達済み最高階 + 1` のみで判定する |
| 記録 | 最深到達階は `TowerClearRecord`（`towerId = "abyss_tower"`）の `highestFloor` に保持する。専用テーブルは追加しない |
| ランキング | ボスラッシュとは別枠（`GET /api/abyss/ranking`、上位100件）。同階の場合は**先に到達したプレイヤーが上位**（更新日時の昇順）。公開範囲・ゲスト時の扱いは §2.11 のランキングと同じ（認証ユーザーのみ登録可、ゲストは閲覧のみ） |

### スケーリング

敵ステータス（HP/ATK/DEF/SPD）と獲得EXP・ゴールドは、いずれも階層に対して指数で増加する。**係数は [master/endgame.md §18.2](../../data/master/endgame.md) が正**（本書では定義しない）。素材ドロップは [master_data.md §10.2](../../data/master_data.md) の深淵の塔の行を適用する。

- 基準値は**天空の塔終盤の通常敵相当**。数値定義は [master/endgame.md §18.1](../../data/master/endgame.md)
- 敵は指数的に強化されるのに対しプレイヤーの成長は線形のため、到達階は自然に頭打ちになる（これが実質的な難易度上限）

### ボスラッシュとの役割分担

| | 深淵の塔 | ボスラッシュ（§2.11） |
|---|---------|---------------------|
| 性質 | **放置型**（常設の周回コンテンツ） | **挑戦型**（全滅で1回の挑戦が終了） |
| 通常の塔探索 | 塔の1つとして扱う（同時進行は不可） | 排他（ボスラッシュ中は塔探索停止） |
| 主目的 | EXP・ゴールド・素材の恒常収入 | 到達ウェーブのランキング競争・マイルストーン報酬 |
| 進行の持ち越し | あり（到達階を保持し途中から再開可） | なし（毎回 Wave 1 から） |

> **設計意図**: 転生の解放条件は LV9999 だが、通常の塔だけでは到達に必要なEXP（約4,000億）の 0.003% しか供給できず、転生が事実上発動しなかった。深淵の塔の指数報酬により LV9999 が「数ヶ月の到達目標」として現実的な射程に入り、転生がエンドコンテンツとして成立する。
