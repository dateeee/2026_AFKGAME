## 15. ボスラッシュデータ（Phase 5〜）

### 15.1 ウェーブ構成

| ウェーブ帯 | 出現タイプ | 強化倍率 |
|-----------|----------|---------|
| Wave 1〜5 | 通常敵。**塔 `00n`（Wave n → 塔 `00n`）の `totalFloors − 1` 階**（最上階ボスの1つ下）の `floorEncounters` をそのまま用いる。体数・LVも同階の定義値のまま | ×1.0 |
| Wave 6〜10 | 既存ボスが順番に登場。**塔 `00(n − 5)` の最上階ボス**1体（Wave6:ゴブリンキング、Wave7:ベヒーモス、Wave8:キングハイドラ、Wave9:ポイズンドレイク、Wave10:バアル） | ×1.0 |
| Wave 11〜 | ボス強化版。Wave nのステータス = Wave10のステータス × (1.1 ^ (n - 10)) | ×1.1〜 |

- Wave 1〜5 を塔ごとの固定構成にするのは、ボスの登場順（Wave 6〜10）と塔番号をそろえて難易度を単調に上げるため。**抽選を行わない**（乱数を消費しない）
- 強化倍率は敵ステータス（HP/ATK/DEF/SPD）と敵の Gold / EXP の両方へ乗じる
- **定期回復率 = 10%**。5ウェーブごと（Wave5、Wave10、Wave15...）の**突破直後**に、生存者へ `effectiveMaxHp` の10%を回復する（適用契機と丸めの正は [tech_bossrush/wave.md §7](../../tech/detail/tech_bossrush/wave.md)）

### 15.2 マイルストーン初回報酬

| 到達ウェーブ | 初回ボーナス |
|------------|-----------|
| Wave 5 | 強化石×10 |
| Wave 10 | 魔法の結晶×5 |
| Wave 15 | 希少鉱石×3 |
| Wave 20 | 古代の欠片×1 |
| Wave 25 | 古代の欠片×2 |
| Wave 30 | 古代の欠片×3 + レジェンダリー装備×1（ランダム） |

- 初回到達時のみ付与（2回目以降は累積報酬のみ）
- Wave 30以降は10ウェーブ刻みで漸増パターン:

| 到達ウェーブ | 初回ボーナス |
|------------|-----------|
| Wave 40 | 古代の欠片×5 + レジェンダリー装備×1（ランダム） |
| Wave 50 | 古代の欠片×8 + レジェンダリー装備×2（ランダム） |
| Wave 60 | 古代の欠片×12 + レジェンダリー装備×3（ランダム） |
| Wave 70+ | 以降10ウェーブごとに古代の欠片+5、レジェンダリー装備+1 |

**付与対象の判定**: `5 <= wave <= 30` かつ `wave` が5の倍数、または `wave > 30` かつ `wave` が10の倍数。

**Wave 70 以降の一般式**（`k = (wave − 70) ÷ 10`、`wave` は10の倍数）:

| 報酬 | 個数 |
|------|------|
| 古代の欠片 | `17 + 5 × k` |
| レジェンダリー装備（ランダム） | `4 + k` |

- 上表は Wave 60（欠片12・装備3）からの漸増を延長したもので、Wave 70 は欠片17・装備4 になる
- 上限を設けない（ウェーブ数に上限が無いため）。装備の抽選方法は装備マスターのレジェンダリー枠から等確率とする（仮置き）

### 15.3 累積報酬（毎ウェーブ）

| 項目 | 定義 |
|------|------|
| 累積報酬係数 | **0.5**（仮置き） |
| 算出式 | ウェーブ突破ごとに `そのウェーブに出現した敵の Gold / EXP の合計 × 累積報酬係数`（小数切り捨て）を加算する |
| Wave 11〜 | §15.1 の強化倍率 `1.1 ^ (n - 10)` を適用した後の Gold / EXP を基準にする（丸めは倍率適用後に1回だけ） |
| 付与時期 | 挑戦中は `boss_rush_states.accumulated_*` に積み、**終了時**（全滅・リタイア）にまとめて付与する（[tech_bossrush/control.md §11](../../tech/detail/tech_bossrush/control.md)） |

## 16. 転生ボーナステーブル（Phase 5〜）

キャラクターが転生するごとに獲得する転生ポイントの投資先。そのキャラクターにのみ適用。

### 16.1 転生ボーナス一覧

| ボーナス | 効果/pt | 上限 | 最大効果 |
|---------|--------|------|---------|
| HP強化 | +1% | 50pt | +50% |
| ATK強化 | +1% | 50pt | +50% |
| DEF強化 | +1% | 50pt | +50% |
| SPD強化 | +1% | 50pt | +50% |
| EXP獲得ボーナス | +2% | 30pt | +60% |
| スキルダメージ強化 | +1% | 30pt | +30% |

- 転生1回で10pt獲得（仮置き）
- 全ボーナスを上限まで投資するには累計260pt = **26回の転生**が必要
- 各ボーナスは上限まで自由に配分可能（例: HP全振り、複数分散など）

### 16.2 転生ボーナスリセット

| 項目 | 仕様 |
|------|------|
| リセット方法 | ゴールドを消費して全転生ポイントを返還（ボーナスはすべてリセット） |
| リセットコスト | `転生回数 × 1,000G`（仮置き）。例: 転生3回目のキャラのリセット = 3,000G |
| 部分リセット | なし（全リセットのみ） |

## 18. 深淵の塔データ（Phase 5〜）

仕様は [systems/endgame.md §2.14](../../design/systems/endgame.md)。塔ID `abyss_tower`、階数無限。

### 18.1 基準値（1F相当）

天空の塔終盤の通常敵を基準とする（通常敵 = `arch_dragon` アークドラゴン LV152、ボス = `celestial_sovereign` 天界の覇王。実データは [towers/010_天空の塔.md](../towers/010_天空の塔.md) §2）。

| 項目 | HP | ATK | DEF | SPD | EXP | ゴールド |
|------|-----|-----|-----|-----|-----|---------|
| 通常敵 | 5,000 | 840 | 345 | 20 | 11,892 | 5,130 |
| ボス（10階ごと） | 72,000 | 880 | 398 | 24 | 52,000 | 26,000 |

### 18.2 スケーリング式

| 対象 | 式 |
|------|-----|
| 敵ステータス | `基準値 × 1.08 ^ (階層 / 10)`（小数切り捨て） |
| EXP・ゴールド | `基準値 × 1.20 ^ (階層 / 10)`（小数切り捨て） |

### 18.3 スケーリング早見表

| 階層 | 敵ステ倍率 | 報酬倍率 | 通常敵HP | 通常敵EXP |
|------|----------|---------|---------|----------|
| 10F | ×1.08 | ×1.20 | 5,400 | 14,270 |
| 50F | ×1.47 | ×2.49 | 7,346 | 29,591 |
| 100F | ×2.16 | ×6.19 | 10,794 | 73,632 |
| 200F | ×4.66 | ×38.34 | 23,304 | 455,910 |
| 300F | ×10.06 | ×237.38 | 50,313 | 2,822,879 |
| 461F | ×34.74 | ×4,469.46 | 173,702 | 53,150,865 |

- 461F は素の melee LV9999（装備・限界突破・転生ボーナスなし）で安定周回できる想定上限（**基準値 HP 4,500 時点の試算。基準値改定に伴う再試算は Phase 5 の詳細設計で行う**）
- 敵は指数、プレイヤーは線形成長のため到達階は自然に頭打ちになる（難易度上限として意図的）

### 18.4 エンカウントプール

| 階層帯 | 出現プール |
|--------|----------|
| 1F〜49F | 塔008〜010 の通常敵 |
| 50F〜149F | 塔009〜010 の通常敵 |
| 150F〜 | 塔010 の通常敵のみ |
| 10の倍数階 | 既存ボス10種からローテーション（001→010の順に循環） |

### 18.5 素材ドロップ

[base.md §10.2](base.md) の「深淵の塔」の行を適用。前半／後半の個数判定は 50F を境界とする（§10.3）。
