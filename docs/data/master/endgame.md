## 16. 転生ボーナステーブル（Phase 5〜）

キャラクターが転生するごとに獲得する転生ポイントの投資先。そのキャラクターにのみ適用。

### 16.1 転生ボーナス一覧

| ボーナス | 効果/pt | 上限 | 最大効果 |
|---------|--------|------|---------|
| HP強化 | +1% | 50pt | +50% |
| ATK強化 | +1% | 50pt | +50% |
| DEF強化 | +1% | 50pt | +50% |
| SPD強化 | +1% | 50pt | +50% |
| EXP獲得ボーナス | +2% | 30pt | +60% |
| スキルダメージ強化 | +1% | 30pt | +30% |

- 転生1回で10pt獲得（仮置き）
- 全ボーナスを上限まで投資するには累計260pt = **26回の転生**が必要
- 各ボーナスは上限まで自由に配分可能（例: HP全振り、複数分散など）

### 16.2 転生ボーナスリセット

| 項目 | 仕様 |
|------|------|
| リセット方法 | ゴールドを消費して全転生ポイントを返還（ボーナスはすべてリセット） |
| リセットコスト | `転生回数 × 1,000G`（仮置き）。例: 転生3回目のキャラのリセット = 3,000G |
| 部分リセット | なし（全リセットのみ） |
