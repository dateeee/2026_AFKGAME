## 10. 素材データ（Phase 4〜）

### 10.1 素材定義

| ID | 名前 | 主な用途 | 出現帯 |
|----|------|---------|--------|
| `enhance_stone` | 強化石 | 装備強化・施設建設 | 全塔（ゴブリンの塔1F〜） |
| `magic_crystal` | 魔法の結晶 | 装備製作・施設建設 | ダンジョン2〜（獣の塔1F〜） |
| `rare_ore` | 希少鉱石 | 高レア装備製作・施設LV上げ | 中盤〜終盤の塔（毒沼の塔〜） |
| `ancient_fragment` | 古代の欠片 | レジェンダリー製作・施設LV8〜10 | 終盤の塔ボスドロップ（業火の塔〜） |

- 所持上限は倉庫の枠に含まれる（装備・素材・換金アイテムすべて共通）
- 各素材のスタック上限: 999個

### 10.2 素材ドロップ率（目安）

| 素材 | 通常敵 | ボス |
|------|--------|------|
| 強化石 | 15-25% | 100%（1-3個） |
| 魔法の結晶 | 10-15% | 80%（1-2個） |
| 希少鉱石 | 5-10% | 50%（1個） |
| 古代の欠片 | - | 10-20%（1個） |

> ドロップ率はドロップ率スケーリング（§2.1参照）の対象。高階層ほど出やすい。

### 10.3 素材ドロップ個数

| 対象 | 個数 |
|------|------|
| 通常敵（塔の前半階層: 1F〜総階数の50%） | 1個固定 |
| 通常敵（塔の後半階層: 総階数の50%超） | 1〜2個（各50%の均等確率） |
| ボス | §10.2 の表の通り（「1-3個」等の範囲表記は均等確率で決定） |

- 例: 森の塔（30階）では 1F〜15F が1個固定、16F〜29F が1〜2個
- 境界は `floor(総階数 × 0.5)` 以下を前半とする
