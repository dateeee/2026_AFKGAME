## 1. 基本情報

| 項目 | 値 |
|------|-----|
| 系統名 | 弱体系統 |
| 系統ID | `debuff` |
| テーマ | デバフ・状態異常 |
| 解放Phase | Phase 3 |
| 概要 | 敵のステータス低下や状態異常付与で戦闘を有利にする系統。高難度コンテンツでの安定攻略の鍵 |

## 5. ダメージ/効果期待値

LV10（ATK37、敵HP200想定）基準の参考値。

| スキル | 効果 | 3ターン合計の貢献 |
|--------|------|-----------------|
| 威圧 | 敵ATK-20%（3T） | 被ダメージ約-18/3T（敵ATK30想定） |
| 毒付与 | maxHP×5%/T（3T） | 合計30ダメージ（HP200の敵） |
| 全体弱化 | ATK/DEF-15%（3T） | 被ダメ軽減+与ダメ増加の複合効果 |

> 弱体延長（+1T）適用時: 威圧4T、毒4T（合計40ダメージ）、全体弱化4T

## 6. シナジー・コンボ

| 組み合わせ | 効果 | 備考 |
|-----------|------|------|
| 弱体 + 魔法 | 全体弱化（DEF-15%）→ メテオで殲滅 | 範囲デバフ+範囲攻撃の組み合わせ |
| 弱体 + 剣術 | 威圧で安全確保 + 高火力単体攻撃 | 万能型構成 |
| 弱体 + 回復 | デバフで被ダメ軽減 + 回復で持久戦 | 安定攻略向き |
| 弱体 + 強化 | バフ+デバフで実質的なステータス差を最大化 | フルサポート構成 |
