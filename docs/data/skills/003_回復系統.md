## 1. 基本情報

| 項目 | 値 |
|------|-----|
| 系統名 | 回復系統 |
| 系統ID | `heal` |
| テーマ | HP回復・蘇生 |
| 解放Phase | Phase 3 |
| 概要 | 味方のHP回復と蘇生を担う系統。パーティの継戦能力を大幅に向上させる |

---

## 2. スキルツリー

```
回復系統
├─ Tier1: ヒール (SP1)
│   └─ Tier2: 回復の心得 [P] (SP1)
│       ├─ Tier3a: 全体回復 (SP2)
│       ├─ Tier3b: リジェネ [P] (SP2)
│       └─ Tier4: 蘇生 (SP3) ─── 前提: 全体回復 または リジェネ
```

- Tier3 は全体回復とリジェネの2分岐（両方習得可能）
- Tier4（蘇生）はTier3のいずれか1つを習得していれば取得可能

## 5. ダメージ/効果期待値

LV10（ATK37）基準の参考値。

| スキル | 計算 | 参考回復量 |
|--------|------|----------|
| ヒール | 37 × 1.5 | 55 HP |
| 全体回復 | 37 × 2.0 × 4人 | 74 HP × 4人 |
| リジェネ | maxHP × 3% | LV10（HP284）で約8 HP/ターン |
| 蘇生 | maxHP × 30% | LV10（HP284）で約85 HP |

> 回復の心得（+20%）適用時: ヒール66、全体回復89×4、蘇生102

## 6. シナジー・コンボ

| 組み合わせ | 効果 | 備考 |
|-----------|------|------|
| 回復 + 生存術（挑発） | タンクが被弾集中 → ヒールで維持 | 鉄板構成 |
| 回復 + 生存術（体力強化） | maxHP+10% → リジェネの回復量増加 | 持久戦向き |
| 回復 + 強化（バフ延長） | 回復スキル自体にはバフ延長は適用されないが、パーティ全体の持久力向上 | サポーター構成 |
