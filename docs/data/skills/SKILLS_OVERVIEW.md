## 1. 共通ルール

スキルシステムは Phase 3 で解放される。詳細な仕様は [game_spec.md § 2.8](../../design/systems/character.md#28-スキルシステムphase-3) を参照。

### スキルポイント（SP）

| 項目 | 仕様 |
|------|------|
| 獲得量 | レベルアップごとに **1 SP** |
| 振り直し | **LV × 50G** で全リセット（全SPが返却される） |

| 段階 | 必要SP | 備考 |
|------|--------|------|
| 1段目 | 1 SP | 入門スキル |
| 2段目 | 1 SP | 基本スキル |
| 3段目 | 2 SP | 上級スキル |
| 4段目 | 3 SP | 最上位スキル |

### ツリー制約

- 同系統の下位スキルを取得していないと上位スキルは習得不可
- 系統間の制約なし（異なる系統を自由に組み合わせ可能）

### アクティブスキル

| 項目 | 仕様 |
|------|------|
| セット枠 | **2枠** |
| 発動条件 | クールダウン完了時に自動使用 |
| 発動制限 | 1ターンに1スキルまで（発動しなければ通常攻撃） |
| 優先度 | **回復 > バフ/デバフ > 攻撃** |

| スキル種類 | 発動条件 | クールダウン目安 |
|-----------|---------|--------------|
| 攻撃スキル | CD完了時に通常攻撃の代わりに使用 | 3-5ターン |
| 回復スキル | 味方HP40%以下 + CD完了 | 4-6ターン |
| バフスキル | 戦闘開始時 + CD完了時 | 5-8ターン |
| デバフスキル | CD完了時に使用 | 4-6ターン |

- 目安を超えるのは Tier4 の一部のみ。`magic_3` メテオ・`heal_3` 蘇生・`debuff_3` 全体弱化 は **CD8** で目安を +2〜3ターン超える（強力な全体・蘇生スキルのため）。`sword_3` 渾身の一撃（CD5）・`buff_3` 英雄の号令（CD8）は目安の範囲内

### パッシブスキル

習得するだけで**全て常時有効**。セット枠は不要。

## 3. 状態異常テーブル

スキルや環境効果によって付与される状態異常の定義。数値は仮置き（プレイテスト調整前提）。

| ID | 名前 | 効果 | 持続ターン | 付与率目安 | 備考 |
|----|------|------|-----------|-----------|------|
| `poison` | 毒 | 毎ターンmaxHP×5%ダメージ | 3T | スキル依存 | DOT。環境毒霧（2%）とは別系統で重複する |
| `stun` | スタン | 1ターン行動不能（確定） | 1T | 40-50% | 短い・確実。付与率が高め |
| `paralysis` | 麻痺 | 毎ターン30%の確率で行動不能 | 2-3T | 25-35% | 長い・確率。付与率が低め |
| `silence` | 沈黙 | スキル使用不可（通常攻撃のみ） | 2-3T | 35-45% | スキル持ちの敵に有効 |

- 状態異常は拡張性を持たせたテーブル設計（将来的に種類追加可能）
- 敵にもスキルを段階的に導入し、沈黙が有効に機能する設計とする
- 環境効果の毒霧（maxHP×2%/ターン）とスキル毒（maxHP×5%/ターン）は別系統として独立処理し、両方同時に適用される

## 4. 系統間シナジー・コンボ表

| 組み合わせ | シナジー効果 | 推奨パーティ構成 |
|-----------|------------|----------------|
| 剣術 + 強化 | ATKバフ → 強撃/渾身の一撃で高火力 | アタッカー |
| 魔法 + 弱体 | DEFデバフ → 全体魔法で殲滅 | 範囲アタッカー |
| 回復 + 生存術 | 挑発で被弾集中 → ヒール/リジェネで耐久 | タンク/ヒーラー |
| 強化 + 回復 | バフ延長 + 回復の心得で持久戦 | サポーター |
| 弱体 + 剣術 | ATKデバフで被ダメ軽減 + 高火力攻撃 | 万能型 |
| 生存術 + 強化 | 挑発タンク + 全体バフで安定攻略 | パーティ安定化 |

## 5. バランス設計方針

### DPS比較基準（LV10 / ATK37 基準）

| カテゴリ | スキル例 | 参考ダメージ | CD | ターンあたりDPS |
|---------|---------|------------|-----|----------------|
| 通常攻撃 | — | 20-30 | 0 | 25 |
| 単体攻撃Tier1 | 強撃 | 55 | 3T | 18（CD込み平均） |
| 単体攻撃Tier4 | 渾身の一撃 | 111 | 5T | 22（CD込み平均） |
| 全体攻撃Tier3 | アイスストーム | 44×敵数 | 5T | 敵数依存 |

> スキルは「瞬間火力」で通常攻撃を上回る設計。CD込みの平均DPSは通常攻撃と同程度〜やや上回る程度に調整。

### SP効率

- 1系統をTier4まで取得: 7SP（LV7で到達可能）※回復系統のみ全スキル取得に9SP（Tier3が2分岐のため）
- 2系統をTier2まで取得: 4SP（LV4で到達可能）
- 序盤は1系統集中、中盤以降は2系統分散が効率的
