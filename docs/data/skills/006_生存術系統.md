### `surv_1` — 挑発

| 項目 | 値 |
|------|-----|
| ティア | 2 |
| タイプ | アクティブ |
| 必要SP | 1 |
| 前提スキル | `surv_p1` |
| 効果 | 3ターン挑発状態（敵の単体攻撃が50%の確率で自分に向く） |
| ダメージ倍率 | — |
| 対象 | 自分（敵の攻撃先を誘導） |
| ダメージ属性 | — |
| 追加効果 | 範囲攻撃には無効 |
| 状態異常付与 | なし |
| CD | 5ターン |
| 発動条件 | CD完了時 |
| AI優先度 | バフ/デバフ（中優先度グループ） |
| 設計メモ | パーティの要。挑発率は50%→スキルティアで最大80%まで上昇予定（拡張スキル）。複数挑発時は確率按分 |

#### 挑発の詳細仕様

| 項目 | 仕様 |
|------|------|
| 挑発率 | 基本50%（将来的にスキルレベルで50%→60%→70%→80%） |
| 非挑発時 | 残りの確率は通常通りランダムターゲット |
| 範囲攻撃 | **挑発無効**（全体攻撃は挑発で吸えない） |
| 複数挑発時 | 合算80%以下: 各挑発者への確率 + 残りランダム |
| | 合算80%超え: 挑発率の比率で**80%を**按分（例: A:80% + B:60% = 140% → A:45.7%, B:34.3%, ランダム:20%） |

- 合算の上限は80%で、常に20%はランダムターゲットに抜ける（正は [systems/battle.md](../../design/systems/battle.md)「確率・軽減率の上限」）

## 5. ダメージ/効果期待値

LV10（ATK37、HP284）基準の参考値。

| スキル | 効果 | 参考値 |
|--------|------|--------|
| 体力強化 | maxHP+10% | HP284 → 312（+28） |
| 挑発 | 被弾50%集中（3T） | パーティ4人なら他3人の被弾率が半減 |
| 被ダメ軽減 | 被ダメ-10% | 被ダメ25 → 22.5（-2.5/hit） |
| 反撃 | 30%でATK×0.5 | 期待値: 37×0.5×0.3 = 5.5/被弾 |

> 挑発+反撃: 3ターンで約4-5回被弾 → 反撃期待回数1.2-1.5回 → 約22-28追加ダメージ

## 6. シナジー・コンボ

| 組み合わせ | 効果 | 備考 |
|-----------|------|------|
| 生存術 + 回復（ヒール） | 挑発で被弾集中 → ヒールで維持 | 鉄板タンク構成 |
| 生存術 + 回復（リジェネ） | 体力強化でmaxHP増 → リジェネ回復量増加 | 自己完結型タンク |
| 生存術 + 強化（守りの祝福） | DEF+30% + 被ダメ-10%の重ね掛け | 超耐久タンク |
| 生存術 + 剣術 | 反撃 + 高ATKで反撃ダメージ増加 | 攻撃型タンク |
