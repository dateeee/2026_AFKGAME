## 2. スキルツリー

```
【系統名】
├─ Tier1: スキル名 (SP1)
│   └─ Tier2: スキル名 (SP1) ─── 前提: Tier1スキル
│       ├─ Tier3a: スキル名 [P] (SP2) ─── 前提: Tier2スキル
│       ├─ Tier3b: スキル名 (SP2) ─── 前提: Tier2スキル
│       │   └─ Tier4a: スキル名 (SP3) ─── 前提: Tier3bスキル
│       └─ ...
```

- `[P]` = パッシブスキル（表記なしはアクティブスキル）
- 同ティア内で分岐がある場合は独立して習得可能
- 上位ティアは直接の前提スキルを習得済みであること
