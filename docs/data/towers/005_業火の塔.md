## 3. 敵ステータス設計方針

- 業火テーマ: 炎と悪魔が支配する灼熱地帯。荒野のダンジョンのフィナーレ
- 炎の小鬼: 高SPD・高ATK。群れで先手を取る最序盤の炎使い
- 溶岩ゴーレム: 超高HP・高DEF・極低SPD。岩石ゴーレムの上位版。割れると溶岩が噴出するイメージ
- ヘルハウンド: 高ATK・高SPD。地獄の炎を纏う猟犬。速くて強い
- ファイアドレイク: 高ATK・中SPD。炎のブレスを吐く小竜
- 業火の悪魔: 高ATK・高DEF。炎を操るデーモン、バランス型
- マグマジャイアント: 超高HP・高DEF・低SPD。溶岩で出来た巨人型タンク
- 炎の魔将: 高ATK・中DEF・中SPD。悪魔軍団の将。高い攻撃力
- 混沌のイフリート: 高ATK・高SPD。炎の魔神。最強通常敵
- バアル: ボス。悪魔王。圧倒的なHP・DEF。長期戦を強いる
