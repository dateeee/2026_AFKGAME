## 3. 敵ステータス設計方針

- 天空テーマ: 神々の領域に踏み込んだ最後の挑戦。竜と天使が守護する聖域
- ワイバーンロード: 高ATK・高HP・中SPD。ワイバーン族の王。強力だが初見向け
- 堕天使: 高ATK・高SPD。神の恵みを失った天使。高速で光の剣を振るう
- 雷竜: 高ATK・超高HP。雷を司る古竜。HPの壁が厚い
- 虚空のドレイク: 高ATK・高HP・中SPD。次元を超える黒竜の亜種
- セラフ: 最高ATK通常敵・高SPD。六翼の熾天使。攻撃面では最強クラス
- 長老竜: 高ATK・超高HP・高DEF。数千年を生きる古代竜。攻守共に高水準
- 神聖ゴーレム: 超高HP・超高DEF・低SPD。神殿を守護する聖なる石像。最強のタンク
- アークドラゴン: 高ATK・超高HP・高DEF・中SPD。竜族の頂点。全能力が極めて高い
- 天界の覇王: ボス。天界を支配する神話級の存在。圧倒的HP・高い全ステータス。長期戦必至
