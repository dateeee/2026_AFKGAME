## 3. 敵ステータス設計方針

- 深海テーマ: 光の届かない深海の闇に潜む巨大生物たち
- 深海鮫: 高ATK・高SPD。超高速で突進する深海の捕食者
- 巨大タコ: 高HP・高DEF・低SPD。墨で視界を塞ぐ。8本腕のタンク型
- 大海蛇: 高ATK・高HP・中SPD。体を巻きつける拘束型
- 深淵エイ: 高ATK・高SPD・中HP。電撃を放つスピード型
- 深海アンコウ: 超高HP・高DEF・低SPD。誘い灯を持つ深海のタンク
- クラーケンの腕: 超高HP・超高DEF・低SPD。クラーケン本体の触手。ほぼ壁
- 深海ベヒーモス: 超高HP・超高DEF・低SPD。深海最大の重装甲生物
- 海龍: 高ATK・高HP・高SPD。海を支配する竜。オールラウンダー上位
- リヴァイアサン: ボス。神話の海の魔獣。圧倒的HP・高いDEF
