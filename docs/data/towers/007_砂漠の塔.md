## 3. 敵ステータス設計方針

- 砂漠テーマ: 古代文明が眠る灼熱の砂漠。アンデッドと砂漠生物が共存
- 砂漠サソリ: 高ATK・高SPD。毒刺しを持つ砂漠の主
- 砂漠大蛇: 高ATK・中SPD。砂の中を潜って急襲する
- 砂の巨像: 超高HP・高DEF・低SPD。砂でできた古代のゴーレム
- ミイラ騎士: 高HP・高DEF・低SPD。呪いの包帯に巻かれた戦士。アンデッド
- ロック鳥: 高ATK・中SPD。巨大な猛禽類。翼で砂嵐を起こす
- アヌビスの番兵: 高ATK・高DEF。死の神の番人。攻守バランスが高い
- 砂漠の巨神: 超高HP・超高DEF・極低SPD。砂漠版の極限タンク
- スフィンクス: 高ATK・高DEF・中SPD。謎かけと戦闘の双方に秀でた知性体
- ファラオリッチ: ボス。不死のファラオ。圧倒的HP・高いDEF、魔法攻撃型
