# 塔一覧 (TOWERS OVERVIEW)

全塔の概要まとめ。各塔の詳細は個別ファイルを参照。

## 設計方針

- 推奨LVは各塔で **約20レベル幅** を確保し、プレイヤーが1塔をじっくり周回できるよう設計
- 隣接する塔と5〜8レベル重複させ、移行が自然に感じられるようにする
- 塔ごとの進行ペース: 約15〜17レベルずつ上昇
- 報酬（Gold/EXP）は前塔比 **2.0〜2.8倍** 程度で推移
