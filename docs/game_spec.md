## 1. 開発フェーズ

### Phase 1 — MVP（最小限デモ）
1画面で基本ループを体験できる最小構成。

- キャラクター1体の自動戦闘
- 敵を倒してゴールド＆経験値を獲得
- レベルアップによるステータス上昇
- オフライン経過時間に応じた報酬蓄積
- 簡易的な戦闘ログ表示
- HPポーションの自動使用
- 塔外でのHP自然回復（時間経過）

### Phase 2 — 基本システム
- 装備システム（武器・防具のドロップと装着）
- 装備強化（素材消費による強化）
- 複数の塔（難易度段階）
- ショップ（ゴールドでアイテム購入）

### Phase 3 — パーティ・編成
- 複数キャラクターの獲得（ガチャ or 塔クリア報酬）
- パーティ編成（最大4体）
- 職業システム（戦士・魔法使い・僧侶・盗賊など）
- スキルシステム（自動発動）

### Phase 4 — 拠点・経営要素
- 拠点建設（鍛冶屋・酒場・訓練場など）
- 施設レベルアップによるボーナス効果
- 冒険者派遣（複数パーティの同時探索）
- 素材収集と生産

### Phase 5 — エンドコンテンツ・拡張
- ボスラッシュ
- 自己ベストランキング（ローカル記録）
- イベントダンジョン
- 転生（プレステージ）システム

## 2. コアシステム仕様

### 2.1 キャラクター

#### ステータス
| パラメータ | 説明 |
|-----------|------|
| HP | 体力。0になると戦闘不能（一定時間で自動回復） |
| ATK | 攻撃力。与ダメージに影響 |
| DEF | 防御力。被ダメージ軽減 |
| SPD | 速度。行動順序に影響 |
| LV | レベル。経験値蓄積で上昇 |

#### レベルアップ
- 必要経験値: `100 * (level ^ 1.5)`
- レベルアップ時に全ステータスが成長率に応じて上昇

#### 職業（Phase 3〜）
| 職業 | 特徴 |
|------|------|
| 戦士 | HP・ATK が高い。前衛タンク兼アタッカー |
| 魔法使い | ATK が非常に高いが HP・DEF が低い。後衛火力 |
| 僧侶 | 回復スキルを持つ。パーティの生存力を上げる |
| 盗賊 | SPD が高い。クリティカル率ボーナス。ドロップ率UP |

### 2.2 戦闘システム

#### 処理方式 — ハイブリッドティック制
戦闘はバックエンド側で **一定間隔（tick）ごとに処理** する。
ブラウザを開いていてもいなくても、サーバー上でゲームが進行する。

| 状態 | 処理方式 | 間隔 |
|------|---------|------|
| オンライン | フロントが定期的にAPIをポーリング | 60秒ごと |
| オフライン | 復帰時にサーバーが経過時間分をまとめて計算 | — |

#### 1 tick の流れ
```
[1 tick = 60秒]

1. 行動順決定（SPD順）
2. 各キャラクターが自動で行動（攻撃 / スキル）
3. ダメージ計算・HP更新
4. 敵撃破判定 → 報酬付与
5. 階クリア判定 → 撤退条件チェック → 次の階 or 撤退
6. 結果を保存 + 戦闘ログ生成
```

#### 基本フロー
```
塔選択（目標階・撤退条件・周回モード設定）→ 1階から自動戦闘開始
→ 各階で1戦闘 → 勝利で次の階へ → tick ごとにオート戦闘
→ 撤退条件到達 or 目標階クリア → 報酬獲得
→ 周回モードに応じて 1階から再突入 or 停止
```

#### 塔進行モード
塔選択時に以下のモードを選択できる:

| モード | 動作 |
|--------|------|
| **自動周回**（デフォルト） | 目標階クリア後、1階から自動で再突入する |
| **クリア後停止** | 目標階クリア後、戦闘を停止する（報酬確認・装備変更などに便利） |

- 進行中にいつでもモードを切り替え可能
- 進行中に **「リタイア」** を選択すると、現在の戦闘が終了した時点で撤退する（戦闘途中で即中断はしない）
- リタイア時、それまでに獲得した報酬は保持される（没収なし）
- オフライン中は選択中のモードに従って自動処理される

#### 目標階設定
- 塔に挑戦する前に **目標階** を設定できる
- 選択可能範囲: 1階 〜 **到達済みの最高階**（初回は1階のみ）
- 目標階に到達しクリアすると、進行モードに応じてループまたは停止する
- 未到達の階は目標に設定できない（新しい階は1階ずつ開拓する）

#### 撤退条件
塔選択時に以下の撤退条件を設定できる（複数同時に有効化可能）:

| 条件 | 動作 |
|------|------|
| **目標階到達**（デフォルト） | 目標階をクリアしたら撤退し、進行モードに従う |
| **HP閾値撤退** | パーティのHPが設定割合（例: 30%）以下になったら、次の階に進まず撤退する |

- **HP閾値のチェックタイミング**: 各階の戦闘が完了した後に判定する。閾値以下であれば次の階に進まず撤退する（その階の報酬は獲得済み）
- HP閾値撤退が発動した場合、それまでに獲得した報酬は保持される
- 撤退後、自動周回モードなら1階から再スタートする
- どの撤退条件も設定しない場合は、目標階到達のみが撤退トリガーとなる
- **全滅時は常に強制撤退**（撤退条件とは独立。詳細は「全滅時の処理」を参照）

#### ターンとtickの関係
- **1ターン = 20秒**、**1 tick = 60秒** → 1 tick内に **3ターン** を処理
- tickごとに3ターン分の戦闘結果をまとめて計算し、ログとして返却

#### 戦闘ルール
- ターン制（SPD順に行動）
- 各キャラクターは毎ターン自動で攻撃対象を選択し攻撃
- ダメージ計算: `damage = ATK * (1 + random(-0.1, 0.1)) - DEF * 0.5`
- クリティカル: 5%の確率で1.5倍ダメージ（盗賊は10%）

#### 全滅時の処理
味方パーティが全滅（全員HP 0）した場合、**常に塔から強制撤退し、戦闘を停止** する（自動周回モードであっても再スタートしない）。
プレイヤーが手動で再出発する必要がある。

**全滅ペナルティ:**
1. **経験値ロスト** — 現在レベル内の蓄積経験値の **50%** を失う（レベルダウンはしない）
2. **ゴールドロスト** — 今回の塔探索中に取得したゴールドを **すべて失う**（塔に入る前の所持ゴールドは影響なし）
3. **アイテムロスト** — 今回の塔探索中に取得したドロップアイテムを **すべて失う**（塔に入る前の所持品は影響なし）

> **設計意図**: 全滅にリスクを持たせることで、目標階設定・撤退条件の戦略的な選択を促す。高い階を狙えば報酬は大きいが、全滅リスクも高まるリスク・リワードのバランス。

#### オンライン時（テキストベース）
- フロントが **60秒ごとにAPIをポーリング** して最新の戦闘結果を取得
- サーバーから受け取った戦闘ログをテキストで順次表示
- ログが自動スクロールで流れ、戦闘経過をリアルタイムに確認可能
- 1 tick（3ターン分）の戦闘ログをまとめて表示

#### オフライン時
- 離脱時の最終処理タイムスタンプを記録
- 復帰時にサーバーが経過時間を計算し、**未処理のtick数分をまとめて戦闘シミュレーション**
- 経過tickごとに正規の戦闘処理（ダメージ計算・敵撃破・報酬付与）を実行
- **オフライン中の目標階は固定**（プレイヤーが設定した階を維持。変更は復帰後に手動で行う）
- オフライン中も塔外待機時のHP自然回復は進行する
- オンライン・オフライン問わず報酬効率は **100%（同一）**
- オフライン報酬の上限: 最大24時間分
- 復帰時に **オフライン報酬サマリーモーダル** を表示
  - 経過時間、処理tick数、倒した敵数、獲得ゴールド、獲得経験値、ドロップアイテム、消費ポーション数

### 2.3 HP回復システム

#### 塔外の自然回復
- 塔にいない間、**時間経過でHPが自然回復** する
- 回復量はステータス依存: `回復量/tick = maxHP * 0.02 + DEF * 0.5`
- 1 tick（60秒）ごとに回復判定
- maxHPに達したら回復停止
- オフライン中も自然回復は進行する（復帰時にまとめて計算）

#### ポーションシステム（Phase 1〜）

戦闘中にHPが一定以下になると、所持しているポーションを **自動で使用** する。

| 項目 | 仕様 |
|------|------|
| 使用条件 | HPが **50%以下** になった時に自動使用（設定で変更可能: 30%/50%/70%） |
| 使用タイミング | 各ターンの行動前に判定 |
| 所持上限 | 99個（種類ごと） |
| 入手方法 | ショップで購入（Phase 1〜） / 敵からドロップ（Phase 2〜） |

#### ポーションの種類
| 名前 | 回復量 | 購入価格 | 解放条件 |
|------|--------|----------|----------|
| HPポーション | maxHPの20% | 25G | 最初から |
| ハイポーション | maxHPの50% | 100G | Phase 2〜 |
| エリクサー | maxHPの100% | 500G | Phase 2〜 |

- Phase 1では **HPポーションのみ** 使用可能
- 使用優先度: 最も回復量の少ないポーションから使用（無駄を減らす）
- 所持ポーション数が0の場合、自動使用は発動しない

> **設計意図**: HP回復なし（周回またぎ含む）の厳しさをポーションで緩和する。ポーションの消費管理が戦略要素となり、ゴールドの使い道にもなる。

### 2.4 装備システム（Phase 2〜）

#### 装備スロット（9スロット）
| スロット | 説明 |
|---------|------|
| 武器 | 攻撃に使用。片手武器と両手武器がある |
| 盾 | 片手武器装備時のみ装備可能。両手武器装備時は使用不可 |
| 頭 | 兜・帽子など |
| 胴体 | 鎧・ローブなど |
| 腕 | 篭手・手袋など |
| 腰 | ベルト・サッシュなど |
| 足 | ブーツ・サンダルなど |
| 耳 | イヤリング・ピアス・ペンダントなど |
| 指輪 | 指輪・お守りなど |

#### 武器分類
| 分類 | 武器種 | 盾 | 備考 |
|------|--------|-----|------|
| 片手武器 | 剣、短剣、メイス | 装備可 | バランス型 |
| 両手武器 | 大剣、槍、弓、杖 | 装備不可 | 高ATKだが盾なし |

#### 装備ステータス
- 各装備にはATK/DEF/HP/SPDのいずれか1つ以上がランダムに付与される
- スロットによる制限はなし（頭装備にATKが付くこともある）
- 付与されるステータスの数はレアリティに依存
- 職業制限なし（どの職業でもすべての装備を装備可能）

#### レアリティ
| レアリティ | 色 | ステータス倍率 | 付与ステータス数 |
|-----------|-----|---------------|----------------|
| コモン | 白 | x1.0 | 1-2 |
| アンコモン | 緑 | x1.3 | 2 |
| レア | 青 | x1.6 | 2-3 |
| エピック | 紫 | x2.0 | 3 |
| レジェンダリー | 橙 | x2.5 | 5 |

#### レアリティ出現率（階層依存）
基本確率（1F時点）:

| レアリティ | 基本確率 |
|-----------|---------|
| コモン | 60.5% |
| アンコモン | 25% |
| レア | 10% |
| エピック | 4% |
| レジェンダリー | 0.5% |

- 階層補正: `補正後確率 = 基本確率 × (1 + 0.03 × 階層)`（上位ほど恩恵大）
- コモン確率は残余（100% − 他の合計）で自動調整

#### ドロップ率
- 通常敵: 各敵に装備ドロップ率を設定（10-20%程度）
- ボス敵: 高確率で装備をドロップ（50-80%）
- ドロップ時にスロット種・レアリティ・ステータスをランダム決定

#### 装備の基礎ステータス値
装備レベル（＝ドロップ元の敵LV相当）に応じた基礎値:
- `基礎値 = floor(敵LV × 1.5 + 2)`
- `実効値 = 基礎値 × レアリティ倍率`
- ステータス種による補正: ATK=×1.0、DEF=×0.7、HP=×5.0、SPD=×0.3

#### 売却価格
- `売却価格 = 5 × レアリティ倍率 × 装備レベル`（端数切り捨て）
- 意図的に安く設定（装備は将来の強化素材として保持推奨）
- ゴールド収入源としては換金アイテム（銅貨の袋等）を使用

#### 入手方法
| 方法 | Phase | 詳細 |
|------|-------|------|
| 敵ドロップ | Phase 2〜 | 塔内の敵を倒した時にランダムドロップ |
| 製作 | Phase 4〜 | 鍛冶屋で素材を消費して製作 |

#### HP吸収装備（Phase 2〜）

通常装備とは別に、**HP吸収効果を持つ特殊装備**が存在する。
攻撃時に与えたダメージの一定割合をHPとして回復する。

| 項目 | 仕様 |
|------|------|
| 分類 | 特殊装備カテゴリ（通常装備とは別に個別定義） |
| 吸収率 | 3〜8%（与ダメージに対する割合、装備ごとに固定） |
| 対象スロット | 全スロットに登場しうる |
| 合計上限 | なし（複数装備で積み重ね可能） |
| 回復計算 | `floor(与ダメージ × 吸収率)` を攻撃時に即時HP回復 |
| 出現条件 | 森の塔（塔2）10F以降の敵からドロップ開始 |
| ショップ販売 | なし（ドロップ専用） |

- 入手方法: 敵ドロップ（Phase 2〜） / 鍛冶屋製作（Phase 4〜）
- 低階層では補助的な回復手段（与ダメ30 × 5% = 1.5HP程度）
- ポーションの代替ではなく、ポーション消費を緩やかに抑える位置づけ
- 具体的な吸収装備の一覧は [master_data.md](master_data.md) を参照

> **設計意図**: 序盤〜中盤はポーション中心のHP管理。吸収装備を入手することで継戦力が徐々に向上し、高階層への挑戦を後押しする。

#### 強化（Phase 4〜）
- Phase 2時点では装備強化なし
- Phase 4の鍛冶屋実装時に強化システムを追加予定
- 不要な装備を強化素材として消費する仕組みを想定

### 2.5 ショップ（Phase 1〜）

#### 概要
ゴールドを消費してアイテムや装備を購入できる。
Phase 1ではポーション販売のみ。Phase 2で装備販売・品揃え更新を追加。

#### 常設商品（在庫無制限）
| カテゴリ | 商品 | Phase |
|---------|------|-------|
| ポーション | HPポーション、ハイポーション、エリクサー | 各ポーションの解放Phaseに準拠 |

- 常設商品はいつでも購入可能。在庫制限なし
- 価格は [master_data.md](master_data.md) を参照

#### 日替わり商品（Phase 2〜）
品揃えが **24時間ごと** に自動更新される装備ラインナップ。

| 項目 | 仕様 |
|------|------|
| 更新間隔 | 24時間（サーバー時刻 00:00 UTC でリセット） |
| 商品数 | 武器2個 + 防具2個 + アクセサリー1個 = 計5枠 |
| レアリティ | コモン〜レアの範囲でランダム抽選（エピック以上はドロップ専用） |
| 在庫 | 各商品1個限り（購入したら次の更新まで補充されない） |
| 価格 | 固定価格テーブル（下記参照） |

#### ショップ装備の位置づけ
- ショップ装備は **「つなぎ」的な位置づけ** で、確実に購入できる代わりに性能は低め
- **ドロップ品の約70%の性能** に設定。メインの強い装備はドロップで入手する設計
- ゴールドの主な使い道は **ポーション購入** および将来の **装備強化・スキル強化**

#### 日替わり商品の価格テーブル（固定価格方式）
レアリティ×カテゴリで固定。シンプルで分かりやすい設計。

| レアリティ | 武器 | 防具 | アクセサリー |
|-----------|------|------|------------|
| コモン | 500G | 400G | 300G |
| アンコモン | 1,500G | 1,200G | 1,000G |
| レア | 4,000G | 3,200G | 2,500G |

> 参考: ゴブリンの塔20F周回 ≈ 450G。コモン武器は約1周分、レア武器は約9周分の貯金が必要。

- 日替わり商品のレアリティはプレイヤーの到達階層に応じてスケーリング
  - 最高到達5F未満: コモンのみ
  - 最高到達5F〜14F: コモン・アンコモン
  - 最高到達15F〜: コモン・アンコモン・レア
- 手動更新（有料リフレッシュ）は Phase 2 では実装しない

#### ショップUI
- 常設タブ / 日替わりタブ の2タブ構成
- 日替わりタブには次回更新までの残り時間を表示
- 購入済みの日替わり商品は「売り切れ」表示

### 2.6 ダンジョン・塔

#### 構成
```
ダンジョン（例: 始まりのダンジョン）
  └─ 塔（例: ゴブリンの塔、森の塔）
       └─ 階層（1F, 2F, ... 20F）← 各階で1回の戦闘
```

- **ダンジョン**: 複数の塔を含むエリア。ストーリー進行で新しいダンジョンが解放される
- **塔**: ダンジョン内の攻略対象。「〇〇の塔」という名前を持つ
- **階層（フロア）**: 塔の中の各階。1階 = 1戦闘。最上階にボスが出現
- クリア条件: 目標階の敵を撃破

#### 塔の進行ルール
- 塔に挑戦するたびに **常に1階からスタート**（途中階からの開始は不可）
- 各階で1回の戦闘を行い、勝利すると次の階へ進む
- 目標階に到達しクリアすると、進行モードに応じてループまたは停止
- HPは階をまたいでも **回復しない**（塔内では連戦扱い）
- **自動周回でも HP は回復しない**（目標階クリア→1F再突入時もHP持ち越し）
- 塔内でのHP回復手段は **ポーション自動使用** のみ（詳細は「ポーションシステム」を参照）

#### 難易度スケーリング
- 階層が上がるほど敵のレベル・ステータスが上昇
- 上層ほどレアドロップ率が上がる（基準率 × (1 + 0.05 × 階層)）
- 塔の難易度が上がるほど階層数も増える（最初の塔: 20階 → 次の塔: 30階 → ...）

#### エンカウントプール
各階の出現敵は固定ではなく、**重み付きプール**からランダムに抽選される。

- 各階に複数の候補敵と出現確率（重み）を設定
- 塔に入るたびに各階の敵が抽選で決定される
- ボス階のみ固定（100%）
- 周回ごとに異なる敵構成になるため、繰り返しプレイの単調さを軽減
- 具体的なプールは [master_data.md](master_data.md) を参照

#### 塔の解放条件
- 次の塔は、前の塔の最上階ボスを討伐すると解放される
- 同ダンジョン内の塔は順番に解放（飛ばし不可）
- 新しいダンジョンは、前のダンジョンの最後の塔をクリアすると解放

#### ダンジョン1: 始まりのダンジョン

| 塔 | 名前 | 階層数 | 推奨LV | 解放条件 | 環境効果 |
|----|------|--------|--------|---------|---------|
| 塔1 | ゴブリンの塔 | 20 | 1-15 | なし（初期） | なし |
| 塔2 | 森の塔 | 30 | 13-25 | ゴブリンキング討伐 | なし |

#### 環境効果（ダンジョン2〜）
ダンジョン2以降の塔には**環境効果（modifier）**が設定される。
塔全体に適用される特殊条件で、入場前にUIで確認可能。

| 種類 | 例 | 効果 |
|------|-----|------|
| ステータス増減 | 瘴気 | プレイヤーATK -10% |
| DOT | 毒霧 | 毎ターンmaxHPの2%ダメージ |
| 制限 | 魔力封印 | ポーション使用不可 or 回復量半減 |
| 回復 | 清浄な水場 | 階クリア後にHP 3%回復 |
| ボーナス | 財宝の塔 | ゴールドドロップ+20% |

- デバフとボーナスを組み合わせてリスク・リワードのバランスをとる
- 効果は塔固有（ランダムではない）
- ステータス増減: 入塔時に適用、LVアップ時再計算
- DOT: 各ターン行動前に判定、ダメージ = `floor(maxHP × rate)`、最低1
- 制限: ポーション自動使用ロジック内で判定
- ボーナス: 報酬計算時に乗算

#### ダンジョン2: 深淵のダンジョン（Phase 2では定義のみ）
解放条件: 森の塔クリア（ベヒーモス討伐）

| 塔 | 名前 | 階層数 | 推奨LV | 環境効果 | テーマ |
|----|------|--------|--------|---------|-------|
| 塔3 | 魔獣の塔 | 35 | 23-35 | SPD-15% + 階クリアHP3%回復 | 魔法生物（環境効果の導入） |
| 塔4 | 毒沼の塔 | 40 | 30-40 | 毒霧(2%/ターン) + ゴールド+20% | 爬虫類・昆虫（リスク・リワード） |
| 塔5 | 煉獄の塔 | 45 | 38-45 | 敵ATK+10% + ポーション半減 | 悪魔系（高難易度） |
