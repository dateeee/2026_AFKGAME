# AFK GAME 用語集

## ゲームメカニクス

### コアループ・戦闘
| 用語 | 英語 | 説明 |
|------|------|------|
| 放置系 | Idle/AFK | アプリを閉じていても進行するゲーム方式 |
| ハイブリッドtick制 | Hybrid Tick System | 60秒間隔のサーバー処理。オンライン時はポーリング、オフライン時は復帰時一括計算 |
| tick | tick | 60秒のサーバー処理単位。1 tick = 3ターン |
| ターン | turn | 20秒の行動単位。1 tick内に3ターン |
| 塔 | tower | 複数階層からなるダンジョン構造（例：ゴブリンの塔） |
| 階 | floor | 塔内の個別戦闘ステージ |
| ダンジョン | dungeon | 複数の塔を含む上位構造（例：始まりのダンジョン） |
| 周回 | loop | 目標階クリア後に1Fから繰り返すこと |
| 自動周回 | auto-repeat | 目標階クリア後に自動で1Fから再開するモード |
| クリア後停止 | stop-on-clear | 目標階クリア後に停止するモード |
| 撤退 | retreat | 塔探索中に退出して報酬を確定する行動 |
| リタイア | retire | 現在の戦闘完了後に塔から撤退する操作 |
| 全滅 | wipe | パーティ全員HP=0 |

### キャラクター・ステータス
| 用語 | 英語 | 説明 |
|------|------|------|
| HP / ATK / DEF / SPD | - | 基本ステータス4種 |
| LV | level | キャラクターレベル（上限9999） |
| EXP | experience | 経験値。レベルアップ必要量 = 100 × LV^1.5 |
| SP | skill point | スキル習得用ポイント。レベルアップ毎に1獲得 |
| タイプ（素質） | type/affinity | キャラの成長傾向（近接/魔力/神聖/敏捷）。変更不可 |
| 成長率 | growth rate | レベルアップ時のステータス上昇量（タイプ別） |
| 限界突破 | limit break | 同一キャラを合成して永続ステータスボーナス獲得（+5%〜+30%） |
| 転生 | prestige | LV9999到達後にリセットし転生ポイントを獲得する永続強化システム |
| 転生ポイント | prestige point | 転生時に獲得（10pt/回）。ステータス・EXP・スキルダメージ等に投資 |
| 転生ボーナス | prestige bonus | 転生ポイントで得る永続的な自己対象倍率 |

### 戦闘・ダメージ
| 用語 | 英語 | 説明 |
|------|------|------|
| 行動順 | action order | SPD降順で決定 |
| ダメージ計算 | damage formula | ATK × (1 ± 0.1) - DEF × 0.5 |
| クリティカル | critical hit | 5%で1.5倍ダメージ |
| 通常攻撃 | normal attack | スキル未使用時の基本攻撃 |
| 範囲攻撃 | AoE | 全体攻撃。単体の0.7倍ダメージ |
| バフ / デバフ | buff / debuff | ステータス増減効果 |
| HP回復（自然） | HP recovery | 塔外で maxHP×0.02 + DEF×0.5 / tick |

### 状態異常
| 用語 | 英語 | 説明 |
|------|------|------|
| 毒 | poison | 5%maxHP/ターンのDOT。3ターン持続 |
| スタン | stun | 1ターン行動不能（発生率40-50%） |
| 麻痺 | paralysis | 30%で行動スキップ。2-3ターン持続（発生率25-35%） |
| 沈黙 | silence | スキル使用不可（通常攻撃のみ）。2-3ターン持続（発生率35-45%） |
| 挑発 | provoke/taunt | 敵の攻撃対象を自分に集中させる（最大80%） |

### スキル
| 用語 | 英語 | 説明 |
|------|------|------|
| スキルツリー | skill tree | 6系統（剣術/魔法/回復/強化/弱体/生存）各4段階 |
| アクティブスキル | active skill | 戦闘中に発動（最大2スロット） |
| パッシブスキル | passive skill | 常時発動の効果 |
| クールダウン (CD) | cooldown | スキル再使用までのターン数（3〜8） |
| 発動条件 | activation condition | スキル使用の条件（CD完了、HP閾値等） |
| 優先度 | priority | 複数スキル発動可能時の順序（回復 > バフ/デバフ > 攻撃） |
| SP振り直し | skill reset | 全スキルリセット＆SP返還（費用: LV×50G） |

### 装備・アイテム
| 用語 | 英語 | 説明 |
|------|------|------|
| スロット | slot | 装備部位（全9箇所：武器/盾/頭/胴体/腕/腰/足/耳/指輪） |
| 武器タイプ | weapon type | 片手武器（盾装備可）と両手武器（盾装備不可） |
| レアリティ | rarity | Common / Uncommon / Rare / Epic / Legendary |
| レアリティ倍率 | rarity multiplier | レアリティ別ステータス倍率（×1.0〜×2.5） |
| ドロップ | drop | 敵撃破時の報酬アイテム |
| ドロップ率 | drop rate | 基本率 × (1 + 0.05 × 階層) |
| 強化（装備） | enhancement | 素材を消費して装備ステータスを上げる |
| 強化レベル | enhancement level | 装備の強化段階（+1〜+10） |
| 分解 | disassemble | 装備を素材に分解 |
| 製作 | crafting | 素材+ゴールドでランダム装備を生成（Phase 4、鍛冶屋） |
| HP吸収 | lifesteal | 与ダメージの3-8%をHPとして回復する装備効果 |
| ポーション | potion | HP回復消費アイテム（自動使用: HP≤閾値で発動） |
| ポーション閾値 | potion threshold | ポーション自動使用のトリガーHP%（10%〜50%、10%刻み。デフォルト30%） |
| 換金アイテム | sellable item | ゴールドに変換するアイテム（銅/銀/金/白金の袋） |
| 素材 | material | 強化石/魔法の結晶/希少鉱石/古代の欠片 |
| インベントリ | inventory | アイテム所持容量（倉庫施設LVで拡張可能） |
| 売却価格 | sell price | 5 × レアリティ倍率 × 装備レベル |
| 自動売却 | auto-sell | 指定レアリティ以下の装備を入手時に自動でゴールド変換（Phase 2〜） |

### ショップ
| 用語 | 英語 | 説明 |
|------|------|------|
| 常設商品 | permanent stock | 常時購入可（ポーション等、無制限） |
| 日替わり商品 | daily rotation | 24h UTC更新の装備ラインナップ（5品） |
| 価格スケーリング | price scaling | レアリティ×アイテム種別による固定価格体系 |

## 技術用語

### アーキテクチャ
| 用語 | 説明 |
|------|------|
| サーバー権威 | 戦闘計算はサーバー側で実行（チート対策） |
| 正規シミュレーション | ≤100 tick: tick毎に完全計算（個別ログ生成あり） |
| 簡略計算 | >100 tick: 統計ベースの近似計算（個別ログなし、サマリーのみ） |
| useBattleLocal.ts | バックエンド未起動時のフロント単体動作（デバッグ用） |
| usePolling.ts | 60秒ポーリング管理のComposable |
| Game State | プレイヤーの全データスナップショット |
| lastTickAt | 最終tick処理のサーバータイムスタンプ |
| Master Data | 静的共有数値定義（敵/塔/キャラ/アイテム） |

### フレームワーク・ライブラリ

|------|------|

| Pinia | Vue 3の公式状態管理ライブラリ |
| SQLAlchemy 2.0 | PythonのORM（データベースアクセス） |
| Pydantic v2 | リクエスト/レスポンスのスキーマバリデーション |
| Alembic | SQLAlchemy用のDBマイグレーション管理ツール |
