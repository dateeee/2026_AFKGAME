## 5. レビュー チェックリスト

機械判定できるもの（lint・型検査の結果）を先に読み、①〜③は残りを目視で潰す。**該当箇所は `ファイル名 行N〜M` で示す**。

| # | 見るもの | 逸脱の例 |
|---|---------|---------|
| 1 | 記述方式 | Options API、`lang="ts"` 欠落、`scoped` 欠落、実行時 props 宣言 |
| 2 | 型 | `any`、`@ts-ignore`、許容パターン外の `as`、非 null アサーション |
| 3 | テンプレート | `:key` 欠落・index キー、`v-if`+`v-for` 同居、複雑な式の直書き、`v-html`、由来不明の `:href` / `:style` |
| 4 | 層 | 画面・部品からの API 直接 import、UI プリミティブのストア依存、生 `fetch` の漏出、`provide` / `inject` |
| 5 | リアクティビティ | `reactive()`、`watchEffect`、getter の副作用、不要な `ref` 化 |
| 6 | クリーンアップ | タイマー・リスナーの解除漏れ、`visibilitychange` の再開判定欠落、ポーリングの停止漏れ |
| 7 | ストア | Options Store、`return` されない state、ストア間の循環、トップレベルでの他ストア確立、楽観更新、`reset()` 欠落 |
| 8 | エラー処理 | メッセージ文字列での分岐、空 `catch`、ローディング・空・エラー状態の欠落、非冪等リクエストの自動リトライ |
| 9 | 命名・置き場 | 接頭辞の不統一、共有型・定数の置き場違反、循環 import |
| 10 | スタイル | 生の16進数・直値、ユーティリティクラス列挙、`:deep()` の乱用、E2E が参照するクラス名の無断リネーム |
| 11 | アクセシビリティ | `div` + `@click`、アイコンボタンの `aria-label` 欠落、ラベル未関連付けの入力、`getByRole` で特定できない操作要素 |
| 12 | スコープ | 対象 Phase 外の機能、仕様書に無い機能、サーバー権威の侵食（フロントでの計算） |

テストコード（E2E）の記述規約・ロケータ戦略・再現性は**本書の対象外**。正の側のテスト分冊が持つ。
