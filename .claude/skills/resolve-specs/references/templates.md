# resolve-specs テンプレート集

`resolve-specs` スキルから参照される出力テンプレート。該当ステップに到達してから読むこと（スキル起動時に読まない）。

## 検討テンプレート（手順3で使用）

```
## 検討: [項目名]

### 背景
- この項目が未確定である理由と、確定が必要な理由
- 既存仕様との関連性（どの仕様に影響するか）

### 制約
- 既に確定済みの仕様から生じる制約条件

### 提案
**案A: [案の名前]（推奨）**
- 内容: ...
- メリット: ...
- デメリット: ...

**案B: [案の名前]**
- 内容: ...
- メリット: ...
- デメリット: ...

（必要に応じて案C）
```

## 完了報告テンプレート（手順6で使用）

```markdown
## 確定報告

### 確定した項目

| 項目 | 確定内容（要約） | 反映先 |
|------|----------------|--------|
| 価格バランス | ゴールド収入の2〜5倍を適正価格帯に設定 | systems/economy.md 2.5 |

### 保留した項目

| 項目 | 保留理由 |
|------|---------|
| ... | （理由） |

### 残りの未確定項目数: N件
（上限を超えて残っている場合はここで「続きは resolve-specs スキルを再実行してください」と案内）
```
